## 📖 故事概要

**故事梗概**：
太阳落山了，天空变成深蓝色，月亮和星星出来了。小明进房间换睡衣、关灯，准备睡觉。妈妈来床边轻轻拍小明，说晚安。小明睡着了，窗外的月亮和星星守护着她。

**主题**：生活（作息）

**目标年龄段**：5-6岁

**新字列表**：晚、月、星、灯、关、门、睡、好、安、如、有、不、了、的（共15字，核心10字）

**故事原文**：
> 太阳落山，天空变成深蓝色，月亮慢慢升起。
>
> 天空中月亮又圆又亮，旁边有几颗小星星。
>
> 天上有很多小星星在闪烁。
>
> 小明走进房间，打开灯，房间亮了。
>
> 小明换好睡衣，准备睡觉。
>
> 小明关上房门。
>
> 小明关上灯，房间暗下来，只有窗外月光。
>
> 小明躺在床上，盖好被子，月光洒在床上，安静温馨。
>
> 妈妈在床边，轻轻拍着小明，小明闭着眼睛微笑。
>
> 小明睡着了，窗外的月亮和星星守护着她，画面充满安全感。

## 📋 插画制作要求

### 技术规格

| 项目 | 要求 |
|------|------|
| 分辨率 | 主图≥1440×1800px |
| 文件格式 | PNG |
| 色彩模式 | RGB |
| 文字区域 | 下方1/3，上方2/3为画面 |

### 画风要求

| 项目 | 要求 |
|------|------|
| 整体风格 | 简约可爱、卡通风格 |
| 线条 | 圆润流畅，3-4px粗细 |
| 色彩 | 夜晚色系，深蓝+暖黄月光 |
| 头身比 | 1:1.5（Q版萌系） |
| 氛围 | 安静、温馨、有安全感 |

### 新字呈现

| 项目 | 要求 |
|------|------|
| 字体 | 圆润可爱的儿童字体 |
| 高亮方式 | 底色高亮 + 边框高亮 |
| 颜色 | 根据新字表分配不同淡色 |
| 对比度 | 与背景有足够对比度 |
