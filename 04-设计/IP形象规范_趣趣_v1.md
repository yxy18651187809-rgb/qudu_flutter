## 一、角色概述

### 1.1 基本设定

| 属性 | 设定 |
|------|------|
| **物种** | 小书虫（拟人化毛毛虫/蚕宝宝） |

```
毛毛虫 → 蜕变成长 → 学习使人成长
书虫   → 热爱阅读 → 产品核心
圆润柔软 → 安全友好 → 降低学习焦虑
```

- 宽度：头部最宽，逐渐变细
- 分段：3-4节，每节之间有轻微凹陷

### 2.2 色彩规范

#### 主色调
| 部位 | 色值 | 说明 |
|------|------|------|
| **身体主色** | `#C5E1A5` | 淡黄绿色，温暖清新 |
| **腹部/肚子** | `#FFF8E1` | 乳白色，增加可爱度 |
| **腮红** | `#FFAB91` | 暖粉色，柔和自然 |
| **头顶叶子** | `#8BC34A` | 春绿色，与品牌色呼应 |
| **眼睛** | `#212121` | 深灰黑色，清晰有神 |
| **高光** | `#FFFFFF` | 纯白色，增加灵动感 |

#### 辅助色（变装使用）
| 等级 | 主题色 | 说明 |
|------|--------|------|
| L1 萌芽 | `#A5D6A7` | 嫩芽绿 |
| L2 成长 | `#FFF176` | 小花黄 |

### 2.3 面部特征详解

#### 眼睛
- **形状**: 正圆形，直径约头部宽度的1/4
- **瞳孔**: 黑色圆形，占眼睛直径的2/3
- **高光**: 白色圆形小点，位于瞳孔左上方，增加灵动感
- **眼白**: 与身体主色一致（淡黄绿），非纯白

#### 眉毛
- **形状**: 简单弧线，位于眼睛上方约1/2眼高处
- **粗细**: 细线条，约2-3px
- **颜色**: 比身体主色深一级的绿色

#### 嘴巴
- **默认状态**: 小巧微笑曲线，呈"⌣"形
- **开心状态**: 张开呈"D"形，可见小舌头
- **惊讶状态": 圆形"O"形
- **睡觉状态": 波浪线"～～"

#### 腮红
- **形状**: 正圆形
- **位置**: 眼睛下方，鼻子两侧
- **大小**: 直径约眼睛的1/2
- **边缘**: 柔和渐变，非硬边

### 2.4 装饰元素

#### 头顶叶子
- **形状**: 椭圆形叶片，尖端略尖
- **大小**: 约头部的1/3大小
- **位置**: 头顶中央偏后
- **叶脉**: 简单1-2条，不复杂
- **动态**: 可随情绪微微摆动

#### 身体纹理
- **类型**: 简单弧线或圆点
- **位置**: 每节身体中央
- **颜色**: 比主色略深的同色系
- **密度**: 稀疏，不密集

#### 手部
- **形状**: 简化小圆球
- **数量**: 每侧一个
- **位置**: 第一节身体两侧
- **功能**: 可拿书、笔等物品

## 三、表情系统（6种基础表情）

### 3.1 微笑表情（默认状态）

**使用场景**: 欢迎页面、默认头像、品牌展示

**面部特征**:
- 眼睛：正常睁开，高光清晰
- 眉毛：自然弧线，微微上扬
- 嘴巴：小巧微笑曲线 ⌣
- 腮红：标准圆形

**身体姿态**: 直立，双手自然下垂或抱书

---

### 3.2 开心表情

**使用场景**: 完成任务、获得奖励、阅读完成

**面部特征**:
- 眼睛：弯成月牙形 ⌒⌒
- 眉毛：明显上扬弧线
- 嘴巴：张开大笑，呈 D 形，可见小舌头
- 腮红：略大，颜色略深

**身体姿态**: 跳跃或挥手，叶子欢快地摆动

**动画建议**: 弹跳动画 + 星星特效

---

### 3.3 思考表情

**使用场景**: 识字学习中、引导思考、测评时

**面部特征**:
- 眼睛：半睁，高光在下方
- 眉毛：一边上扬，一边下垂（不对称）
- 嘴巴：抿嘴，呈 一 字形
- 腮红：标准

**身体姿态**: 单手托腮，身体微倾

**动画建议**: 缓慢眨眼 + 叶子轻微抖动

---

### 3.4 惊讶表情

**使用场景**: 发现新字、互动反馈、遇到惊喜

**面部特征**:
- 眼睛：睁大，瞳孔缩小
- 眉毛：高高扬起，呈 ∧∧ 形
- 嘴巴：圆形 O 形
- 腮红：略小，位置略高

**身体姿态**: 后仰，双手举起

**动画建议**: 快速缩放 + 感叹号弹出

---

### 3.5 眨眼表情

**使用场景**: 鼓励、加油打气、互动反馈

**面部特征**:
- 眼睛：一只睁开，一只 wink（⌒）
- 眉毛：一边上扬
- 嘴巴：调皮微笑
- 腮红：略红

**身体姿态**: 侧身，单手竖起大拇指

**动画建议**: 快速眨眼 + 小星星闪烁

---

### 3.6 睡觉表情

**使用场景**: 休息提醒、晚安模式、加载等待

**面部特征**:
- 眼睛：闭合，呈 ～～ 形
- 眉毛：放松，自然下垂
- 嘴巴：小波浪线 ～～
- 腮红：淡粉色，朦胧感

**身体姿态**: 蜷缩或侧卧，叶子垂下

**动画建议**: 缓慢呼吸起伏 + Zzz 飘出

## 四、分级变装系统（L1-L5）

### 4.1 L1 萌芽级

**主题**: 种子/嫩芽

**装饰元素**:
- 头顶：小嫩芽（两片叶子）
- 身体：绿色小披风
- 配色：嫩芽绿 `#A5D6A7`

**场景应用**: 启蒙阶段、新手引导

---

### 4.2 L2 成长级

**主题**: 幼苗/小花

**装饰元素**:
- 头顶：一朵小黄花
- 身体：黄色小围裙
- 配色：小花黄 `#FFF176`

**场景应用**: 起步阶段、基础阅读

---

### 4.3 L3 开花级

**主题**: 花朵/蝴蝶

**装饰元素**:
- 头顶：花环头饰
- 背部：彩色小翅膀（蝴蝶翅膀简化版）
- 配色：花朵粉 `#F48FB1`

**场景应用**: 发展阶段、自主阅读

---

### 4.4 L4 结果级

**主题**: 果实/丰收

**装饰元素**:
- 头顶：果实造型帽子
- 身体：橙色小背包
- 配色：果实橙 `#FFCC80`

**场景应用**: 提升阶段、进阶阅读

---

### 4.5 L5 飞翔级

**主题**: 蝴蝶/星空

**装饰元素**:
- 头顶：星星发饰
- 背部：大蝴蝶翅膀
- 配色：星空紫 `#B39DDB`

**场景应用**: 进阶阶段、高级阅读

## 五、尺寸规范

### 5.1 标准尺寸

| 用途 | 尺寸 | 格式 | 备注 |
|------|------|------|------|
| 头像 | 64×64px | PNG | 圆形裁剪 |
| 小图标 | 32×32px | PNG | 全身简化 |
| 全身标准 | 200×280px | PNG | 常用尺寸 |
| 全身高清 | 400×560px | PNG | 宣传物料 |
| 矢量源文件 | 无限缩放 | SVG/AI | 设计源文件 |

### 5.2 安全区域

```
┌─────────────────────────┐
│                         │
│    ┌─────────────┐      │
│    │             │      │  ← 10% 安全边距
│    │   趣趣主体   │      │
│    │             │      │
│    └─────────────┘      │
│                         │
└─────────────────────────┘
```

- 四周各留10%空白边距
- 重要面部特征避开边缘10%
- 背景对比度确保角色可见

### 5.3 最小尺寸

- **头像**: 32×32px（再小会丢失细节）
- **全身**: 100×140px（保持可识别性）

## 六、应用规范

### 6.1 禁用规范

❌ **不可做**:
- 拉伸变形（保持比例）
- 改变主色（保持品牌识别）
- 添加额外阴影/描边（官方素材已处理）
- 遮挡面部（保持表情可见）
- 旋转超过45度（保持正面识别）
- 与其他元素重叠（保持清晰）

### 6.2 背景适配

| 背景类型 | 适配建议 |
|----------|----------|
| 浅色背景 | 直接使用 |
| 深色背景 | 添加浅色光晕 |
| 复杂背景 | 添加半透明遮罩 |
| 照片背景 | 保持角色在清晰区域 |

### 6.3 组合规范

**与文字组合**:
- 角色在左/上，文字在右/下
- 保持适当间距（约角色高度的1/4）

**与图标组合**:
- 角色为主，图标为辅
- 图标大小不超过角色的1/3

**与其他角色组合**:
- 趣趣为主角，其他角色为辅
- 保持趣趣在视觉焦点位置
