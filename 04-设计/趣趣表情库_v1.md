## 二、首批5个表情

### 表情1：开心 😊

**使用场景**：完成任务、获得奖励、正确答题

**视觉设计**：

```
        🍃
        
    ╭──────────╮
    │  ◕ ω ◕  │ ← 眼睛弯弯（眯眼笑）
    │    ᴗ    │ ← 大微笑（张嘴）
    │  ˶ˊ˶   │ ← 腮红明显
    ╰──────────╯
      ╰──────╯
```

**面部细节**：
- 眼睛：弯成月牙形（^ ^），眼尾下垂
- 嘴巴：张开大笑，露出小白牙
- 腮红：圆形，#FFAB91，透明度80%
- 整体：身体微微上扬

**颜色**：主色 #C5E1A5，腮红 #FFAB91

**导出尺寸**：
- @1x: 48×48dp
- @2x: 96×96dp
- @3x: 144×144dp

### 表情2：思考 🤔

**使用场景**：识字学习中、引导思考、遇到难题

**视觉设计**：

```
        🍃
        
    ╭──────────╮
    │  ◉ ᴗ ◉  │ ← 一只眼睛睁大，一只半闭
    │    ─    │ ← 嘴巴抿成一条线
    │  ˶ˊ˶   │ ← 腮红淡
    ╰──────────╯
      ╰──────╯
         👆 ← 头顶叶子倾斜（手托腮姿势）
```

**面部细节**：
- 左眼：正常大小，黑色瞳孔+高光
- 右眼：半闭状态（一条弧线）
- 嘴巴：抿成一条水平线（或微微张开）
- 手：头顶叶子旁有一只小手（简化圆球）托住叶子
- 叶子：微微倾斜，表现"歪头思考"
- 腮红：淡粉色

**颜色**：主色 #C5E1A5，腮红 #FFAB91（淡）

---

### 表情3：鼓励 💪

**使用场景**：加油打气、倒计时结束、失败后重新开始

**视觉设计**：

```
        🍃
        
    ╭──────────╮
    │  ◕ ◕   │ ← 眼睛大睁，炯炯有神
    │    ◡    │ ← 闭眼微笑（自信）
    │  ˶ˊ˶   │ ← 腮红
    ╰──────────╯
      ╰──────╯
        ✊ ← 小拳头举起
```

**面部细节**：
- 眼睛：两只都大睁，黑眼珠大而圆，高光亮眼
- 嘴巴：闭眼微笑（U形），自信感
- 手：一侧有小拳头举起（简化圆球）
- 身体：微微倾斜，有动感
- 腮红：明显，表现热情

**颜色**：主色 #C5E1A5，腮红 #FFAB91（明显）

---

### 表情4：欢呼 🎉

**使用场景**：获得高分、庆祝升级、完美通关

**视觉设计**：

```
        🍃🍃 ← 双叶子（兴奋）
        
    ╭──────────╮
    │  ★ ω ★  │ ← 眼睛变成星星（兴奋）
    │    ◡    │ ← 大笑（张嘴）
    │  ˶ˊ˶   │ ← 腮红满脸
    ╰──────────╯
      ╰──────╯
      /       \ ← 身体两侧伸出小手臂（欢呼）
```

**面部细节**：
- 头顶：两片叶子竖起（兴奋）
- 眼睛：变成星星形状（★ ★）
- 嘴巴：张开大笑，比"开心"更大
- 身体：两侧伸出小手臂（简化圆球），向上挥舞
- 腮红：满脸红色，表现极度兴奋
- 周围：可有光芒/星星点缀

**颜色**：主色 #C5E1A5，腮红 #FF7043（通红）

---

### 表情5：惊讶 😲

**使用场景**：发现新字、遇到意外、学习新知识

**视觉设计**：

```
        🍃
        
    ╭──────────╮
    │  ◉ ○ ◉  │ ← 一只眼大睁，一只圆睁
    │    ○    │ ← 嘴巴变成O形（惊讶）
    │         │ ← 无腮红（惊讶时脸白）
    ╰──────────╯
      ╰──────╯
```

**面部细节**：
- 眼睛：两只都圆睁，黑眼珠小（惊讶时瞳孔收缩）
- 高光：眼睛里有大高光点
- 嘴巴：变成圆形O，表示惊讶
- 身体：整体微微后仰（惊讶反应）
- 叶子：微微上扬
- 腮红：无（惊讶时无腮红）

**颜色**：主色 #C5E1A5，无腮红

## 五、技术实现

### 5.1 SVG 导出建议

每个表情导出为独立 SVG 文件：
- `ququ_happy.svg`
- `ququ_thinking.svg`
- `ququ_cheer.svg`
- `ququ_excited.svg`
- `ququ_surprised.svg`

### 5.2 Flutter 集成

```dart
enum QuquExpression {
  happy,
  thinking,
  cheer,
  excited,
  surprised,
}

// 使用方式
Image.asset('assets/images/ququ/ququ_${expression.name}.png')
```

### 5.3 动画建议

| 表情 | 建议动画 |
|------|---------|
| 开心 | 身体上下弹跳（2s周期） |
| 思考 | 叶子左右摇摆，头微微倾斜 |
| 鼓励 | 小拳头上下挥动 |
| 欢呼 | 整体旋转+星星飞散 |
| 惊讶 | 身体快速后仰+恢复 |
