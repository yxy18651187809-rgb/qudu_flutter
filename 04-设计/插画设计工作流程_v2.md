# 插画设计工作流程 v2.0

**优化目标**：根据教研员材料直接设计插画，减少沟通成本  
**适用场景**：L1-12及后续所有故事的插画设计  
**流程负责人**：WorkBuddy (team-lead)

---

## 核心优化点

### v1.0 流程（旧版 - 需优化）
```
教研员材料 → WorkBuddy初步分析 → 向教研员确认问题 → 等待回复 
→ 创建设计文档 → 再次确认 → 插画师执行
```
**问题**：至少需要2轮确认，耗时1-2天

### v2.0 流程（优化后）
```
教研员材料 → WorkBuddy直接产出完整设计文档 → 插画师执行
```
**优势**：0轮确认，即时交付，1小时内完成

---

## 默认决策规则表

对于常见的需要确认的问题，建立以下默认规则：

| 问题类型 | 默认决策 | 理由 | 例外情况 |
|---------|---------|------|---------|
| **数字显示格式** | 标准字体 + 黄色字卡高亮 | L1-11已确认，符合教学需求 | 教研员特别说明时 |
| **QuQu IP出现位置** | 末尾页 + "真棒！"台词 | 鼓励机制，固定模式 | 故事情节不适合时 |
| **新字高亮方式** | 黄色圆角字卡 + 上下文句子 | 视觉突出，易于识别 | - |
| **角色设计风格** | Q版1:1.5头身比 + 莫兰迪色系 | 已验证的视觉风格 | - |
| **分镜页数** | 10-12页（灵活） | 适配App阅读体验，复杂故事可12页 | 特别简单的故事可8页 |
| **新字覆盖检查** | 必须100%覆盖新字表 | 教学质量底线 | - |
| **复习字处理** | 标注"（复习字）" + 不单独高亮 | L2标准已确认 | - |

## 自动化工作流程

### 输入
- 教研员材料：`01-内容/故事教案_XX.md`
  - 包含：新字表、故事情节、教学目标

### 处理步骤（WorkBuddy自动执行）

#### Step 1：解析教研员材料（5分钟）
- 提取新字表 → 生成"新字分布表"
- 提取故事情节 → 推断角色清单
- 提取教学目标 → 确定新字高亮优先级

#### Step 2：应用默认决策规则（0分钟）
- 自动应用"默认决策规则表"中的所有规则
- 无需人工确认

#### Step 3：生成角色设定（10分钟）
- 根据故事情节自动推断角色
- 生成ASCII art示意图
- 应用Q版1:1.5头身比 + 莫兰迪色系

#### Step 4：设计分镜脚本（30分钟）
- 分配新字到各页码（确保100%覆盖）
- 设计每页画面（角色+背景+新字高亮）
- 生成ASCII布局图
- 提取对应文案

#### Step 5：输出4个文档（5分钟）
- 插画师对齐回执
- 角色设定v1
- 分镜脚本v1
- 颗粒度对齐确认书v1

#### Step 6：交付插画师（立即）
- 通过SendMessage直接发送文档给插画师
- 附带执行指南："可直接开始，无需确认"

**总计时间**：约50分钟-1小时  
**沟通次数**：0次

## 质量保证机制

### 自动检查清单
在输出文档前，WorkBuddy自动检查：
- [ ] 新字覆盖率 = 100%
- [ ] 分镜页数 = 10页
- [ ] 所有角色都有设计规范
- [ ] 每页都有ASCII布局图
- [ ] QuQu IP在末尾页
- [ ] 复习字已标注"（复习字）"

### 插画师反馈机制
插画师在执行过程中如遇问题：
1. **技术问题**（如某个姿势难画）：自行基于最佳实践调整，记录到"待优化清单"
2. **教学问题**（如新字高亮不清晰）：通过SendMessage告知WorkBuddy，下次优化
3. **无需反馈**：如一切正常，无需发送任何消息

### 持续优化
每完成3个故事，WorkBuddy自动优化：
- 更新"默认决策规则表"（如有新的最佳实践）
- 优化模板（如有重复性的改进点）
- 更新ASCII art示意图库（如有新的通用角色）
