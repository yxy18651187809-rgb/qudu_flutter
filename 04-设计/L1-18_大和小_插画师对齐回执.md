## 🎯 核心要求摘要

### 角色规范

| 角色 | 外观 | 颜色 | 关键特征 |
|------|------|------|---------|
| 大象 | 灰色，圆润，大耳朵长鼻子 | 灰色 | 温和善良 |
| 小老鼠 | 浅棕色，小巧，长尾巴 | 浅棕色 | 机灵活泼 |
| QuQu | 橙色圆形IP | 橙色+白色 | 引导者 |

### 场景规范

| 页码 | 场景 | 关键元素 |
|------|------|---------|
| P1-P10 | 草地 | 暖黄色背景，绿色草地 |

### 对比呈现要求

| 对比项 | 大 | 小 |
|--------|----|----|
| 身体 | 大象 | 小老鼠 |
| 高低 | "高"字 | "低"字 |
| 长短 | 长鼻子/长尺子 | 短尾巴/短尺子 |
| 果子 | 大树多 | 小树少 |
| 嘴巴 | 大口 | 小口 |
| 喝水 | 大桶 | 小杯 |

### 新字高亮

**核心11字**：`大`、`小`、`多`、`少`、`高`、`长`、`是`、`好`、`有`、`不`、`如`

| 字 | 颜色 | 位置 |
|----|------|------|
| 大 | 淡蓝色 | 右上角/中央/左上方 |
| 小 | 淡绿色 | 左下角/右下方 |
| 多 | 淡橙色 | 右下角/左上方 |
| 少 | 淡红色 | 左上角/右下方 |
| 高 | 淡黄色 | 大象头顶 |
| 长 | 淡青色 | 中央 |
| 是 | 淡蓝色 | 中央 |
| 好 | 淡粉色 | 中央 |
| 有 | 淡绿色 | 右下角 |
| 不 | 淡红色 | 左下角 |

### 技术规格

| 项目 | 要求 |
|------|------|
| 分辨率 | 主图≥1440×1800px |
| 文件格式 | PNG |
| 色彩风格 | 暖黄色背景，莫兰迪色系 |
| 头身比 | 1:1.5（Q版萌系） |
| 对比要求 | 大小对比要直观明显 |
