## 📖 故事概要

**故事梗概**：
大象和老鼠是一对好朋友。大象很大，老鼠很小，但他们都很好。大象的长鼻子长长的，老鼠的尾巴短短的。大树果子多，小树果子少。大的好，小的也好，都好！

**主题**：认知（对比）

**目标年龄段**：5-6岁

**新字列表**：大、小、多、少、高、低、长、短、如、有、不、是、好、的（共14字，核心11字）

**故事原文**：
> 一只大象站在草地上，旁边画一个大大的"大"字。
>
> 一只小老鼠站在大象脚边，旁边画一个小小的"小"字。
>
> 大象和小老鼠站在同一画面中，大象头顶标"高"，老鼠头顶标"低"。
>
> 大象的鼻子伸得长长的，旁边画一把长尺子。老鼠的尾巴短短的，旁边画一把短尺子。
>
> 大树上结了很多果子，小树上只有两三个果子。
>
> 大象和小老鼠站在一起，大象占了大部分画面，老鼠很小。
>
> 大象张开大嘴吃东西，老鼠张开小嘴吃东西。
>
> 大象喝一大桶水，老鼠喝一小杯水。
>
> 大象和小老鼠抱在一起，背景有爱心。
>
> 大象让小老鼠坐在自己头上，一起看远方。画面温馨。

## 📋 插画制作要求

### 技术规格

| 项目 | 要求 |
|------|------|
| 分辨率 | 主图≥1440×1800px |
| 文件格式 | PNG |
| 色彩模式 | RGB |
| 文字区域 | 下方1/3，上方2/3为画面 |

### 画风要求

| 项目 | 要求 |
|------|------|
| 整体风格 | 简约可爱、卡通风格 |
| 线条 | 圆润流畅，3-4px粗细 |
| 色彩 | 暖黄色背景，莫兰迪色系 |
| 头身比 | 1:1.5（Q版萌系） |
| 对比呈现 | 大小对比要直观明显 |

### 新字呈现

| 项目 | 要求 |
|------|------|
| 字体 | 圆润可爱的儿童字体 |
| 高亮方式 | 底色高亮 + 边框高亮 |
| 颜色 | 根据新字表分配不同淡色 |
| 对比度 | 与背景有足够对比度 |
