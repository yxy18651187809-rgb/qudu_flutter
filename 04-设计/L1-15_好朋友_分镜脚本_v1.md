## 📖 故事概要

**故事梗概**：
小明和小红是一对好朋友。他们在阳光明媚的公园里一起玩耍、分享，度过快乐的一天。傍晚分别时，他们约定明天还要一起玩。

**主题**：友谊（社交）

**目标年龄段**：5-6岁

**新字列表**：好、朋、友、一、起、玩、笑、乐（共8字）

**故事原文**：
> 阳光明媚的公园里，小明和小红并肩站着，两人脸上带着微笑。
>
> 小明举起一只手，向小红招手。
>
> 两人在草坪上玩皮球，皮球在空中飞。
>
> 小明拍球成功，小红为他鼓掌。
>
> 小红也笑了，两人对视微笑。
>
> 两人坐在草坪上休息，分享一瓶水。
>
> 太阳公公笑眯眯挂在天空，洒下金色阳光。
>
> 小明和小红一起指向天上的白云。
>
> 傍晚时分，两人在公园门口挥手告别。
>
> 月亮升起来了，星星闪烁。小明和小红各自回到家，躺在床上，闭眼微笑。

## 📋 插画制作要求

### 技术规格

| 项目 | 要求 |
|------|------|
| 分辨率 | 主图≥1440×1800px |
| 文件格式 | PNG |
| 色彩模式 | RGB |
| 文字区域 | 下方1/3，上方2/3为画面 |

### 画风要求

| 项目 | 要求 |
|------|------|
| 整体风格 | 简约可爱、卡通风格 |
| 线条 | 圆润流畅，3-4px粗细 |
| 色彩 | 明亮活泼，低饱和度暖色系 |
| 头身比 | 1:1.5（Q版萌系） |

### 新字呈现

| 项目 | 要求 |
|------|------|
| 字体 | 圆润可爱的儿童字体 |
| 高亮方式 | 底色高亮（淡色背景）+ 边框高亮 |
| 颜色 | 根据新字表分配不同淡色 |
| 位置 | 按照分镜脚本指定位置 |
| 对比度 | 与背景有足够对比度，清晰可辨 |
