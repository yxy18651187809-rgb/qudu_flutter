| 属性 | 设定值 | 设计依据 |
|------|--------|----------|
| 物种 | 拟人化小白兔 | 儿童最熟悉的动物之一 |

| 年龄感 | 5-6岁 | 与目标读者同龄，有代入感 |

### 2.3 色彩规范（精确值）

## 三、配角：小鸟（C03）

### 3.1 基本参数

| 属性 | 设定 | 说明 |
|------|------|------|
| 物种 | 黄色小鸟 | 常见儿童友好角色 |
| 角色定位 | 第1页配角 | 与红苹果一起出场 |
| 大小比例 | 约为小兔子的1/4 | 明确主次关系 |
| 头身比 | 1:1（Q版圆胖） | 圆润可爱 |

### 3.2 造型设计

```
      ╱▽╲        ← 头部：圆形
     ╱    ╲
    │ ◉ ◉ │      ← 眼睛：小圆点，间距接近
     ╲  ⏗ ╱      ← 嘴巴：橙色小三角
      ‖▔▔‖
    ╱━━━━╲       ← 身体：椭圆形
   │ ▓▓▓▓ │      ← 身体黄色填充
    ╲━━━━╱
     ╱  ╲        ← 翅膀：小三角形
     ◯          ← 脚：纤细短小
```

### 3.3 色彩规范

| 部位 | 色值 | 说明 |
|------|------|------|
| 身体羽毛 | `#FFD54F` | 柔和金黄色，偏暖 |
| 肚子 | `#FFF9C4` | 浅黄色，增加层次 |
| 嘴巴 | `#FF8A65` | 暖橙色，柔和 |
| 脚 | `#FF8A65` | 与嘴巴同色 |
| 眼睛 | `#212121` | 深色小圆点 |
| 翅膀 | `#FFCA28` | 比身体稍深 |

### 3.4 出场姿势

- **第1页**：站在画面右侧的树枝上，头微侧，看向小兔子手中的红苹果
- **表情**：好奇，眼睛微微睁大
- **尺寸**：约画面高度的1/6

## 四、配角：小鸡（C04）

### 4.1 基本参数

| 属性 | 设定 | 说明 |
|------|------|------|
| 物种 | 黄色小鸡 | 与鸡蛋场景匹配 |
| 角色定位 | 第2页配角 | 2只小鸡，数量呼应"二" |
| 大小比例 | 约为小兔子的1/3 | 比小鸟稍大 |
| 头身比 | 1:1（Q版圆胖） | 绒毛质感 |

### 4.2 造型设计

```
      ╱▽╲        ← 头部：圆形，绒毛质感
     ╱    ╲
    │ ◉ ◉ │      ← 眼睛：小黑点
     ╲  ⏗ ╱      ← 嘴巴：橙色小三角，比小鸟稍大
      ‖▔▔‖
    ╱━━━━╲       ← 身体：圆润椭圆形，比头部大1.5倍
   │ ▓▓▓▓ │      
    ╲━━━━╱
     ╱  ╲        ← 翅膀：短小圆润
     ◯  ◯       ← 脚：橙色三趾
```

### 4.3 色彩规范

| 部位 | 色值 | 说明 |
|------|------|------|
| 绒毛主色 | `#FFF8E1` | 米黄色，柔软温暖 |
| 绒毛阴影 | `#FFE082` | 浅杏黄，表现蓬松 |
| 嘴巴 | `#FF8A65` | 暖橙色 |
| 脚 | `#FF8A65` | 与嘴巴同色 |
| 眼睛 | `#212121` | 小黑点 |

### 4.4 出场姿势

- **第2页**：2只小鸡位于画面下方，小兔子脚边
- **姿态**：一只抬头看小兔子，一只低头看鸡蛋
- **表情**：可爱天真
- **间距**：两只小鸡间约1个小鸡宽度

## 五、配角：蝴蝶（C05）

### 5.1 基本参数

| 属性 | 设定 | 说明 |
|------|------|------|
| 角色定位 | 第3页配角 | 3只蝴蝶，数量呼应"三" |
| 大小比例 | 每只约为小兔子头部的1/2 | 在画面中飞舞 |
| 翅膀 | 各有不同配色 | 增加画面丰富度 |

### 5.2 造型设计（以蝴蝶1号为例）

```
       ╱╲  ╱╲         ← 前翅：大圆形
      ╱▓▓╲╱▓▓╲        ← 翅膀带花纹斑点
      ╲  ╲╱  ╱
       ╲ ●● ╱         ← 身体：细长
        ╲▽╱           ← 头部：小圆形
         ▐▌            ← 身体：细长椭圆形
         ▐▌
       ╱ ╲╱ ╲         ← 后翅：小圆形
      ╱▓▓  ▓▓╲
```

### 5.3 色彩规范（3只蝴蝶各不同配色）

| 蝴蝶 | 翅膀主色 | 斑点色 | 身体 | 设计意图 |
|:---|:---|:---|:---|:---|
| 蝴蝶1 | `#F48FB1` 粉 | `#FFFFFF` 白斑 | `#795548` 棕 | 柔和粉，吸引女童 |
| 蝴蝶2 | `#64B5F6` 蓝 | `#FFF176` 黄斑 | `#795548` 棕 | 清爽蓝，平衡色盘 |
| 蝴蝶3 | `#FFB74D` 橙 | `#FFFFFF` 白斑 | `#795548` 棕 | 温暖橙，丰富画面 |

### 5.4 出场姿势

- **第3页**：3只蝴蝶在空中飞舞，分布在画面的左上、右上、中下
- **飞行轨迹**：曲线型，呈现灵动感
- **翅翼角度**：每只蝴蝶翅膀张开角度不同（45°/60°/90°），避免重复
