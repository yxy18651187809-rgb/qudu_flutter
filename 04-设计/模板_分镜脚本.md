## 多新字排版指南（自动应用）

### 适用场景
当一页有2个或以上新字时，需要精心设计字卡位置，避免重叠。

### 排版原则
1. **错开位置**：字卡不能重叠，需分布在画面的不同区域
2. **靠近对应实物**：字卡位置靠近对应实物（如"鱼"字卡靠近鱼儿图片）
3. **不遮挡角色脸部**：字卡不能放在角色脸部前面
4. **保持画面平衡**：字卡分布要均匀，不能"一边倒"

### 排版示例

#### 示例1：一页2个新字
```
+----------------------------------+
|  字卡1 ← 左侧                 |
|                                  |
|        [角色]                    |
|                                  |
|                 字卡2 ← 右侧   |
+----------------------------------+
```

#### 示例2：一页3个新字
```
+----------------------------------+
|  字卡1 ← 左上                |
|                                  |
|        [角色]        字卡2 ← 右上|
|                                  |
|                 字卡3 ← 下方   |
+----------------------------------+
```

#### 示例3：一页4个新字（极限情况）
```
+----------------------------------+
|  字卡1 ← 左上    字卡2 ← 右上|
|                                  |
|        [角色]                    |
|                                  |
|  字卡3 ← 左下    字卡4 ← 右下|
+----------------------------------+
```

**重要提醒**：一页4个新字是极限情况，尽量避免。如不可避免，需精心安排字卡位置。

### 字卡尺寸调整

- 3个新字/页：字卡尺寸约100×50px（进一步缩小）
