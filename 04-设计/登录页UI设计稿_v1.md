## 二、区域详解

### 2.1 Logo 区域

```
         ┌────────────────┐
         │                │
         │    🐛(趣趣)   │  ← 趣趣IP形象，小尺寸
         │                │
         │   字趣阅读     │  ← App名称
         │                │
         └────────────────┘
```

**规范**：
- 趣趣图标：64×64dp，顶部留 80dp 空间
- App名称：textH1（28sp），圆润手写体，颜色 textPrimary
- Logo区总高度：约 160dp

### 2.2 手机号输入框

```
┌──────────────────────────────────────┐
│  🇨🇳 +86                        │ ← 前缀（不可编辑）
│  请输入手机号                        │ ← hint文字
└──────────────────────────────────────┘
```

**规范**：
- 容器：白色背景，1.5dp边框（#E0E0E0），圆角12dp
- 高度：48dp
- 内边距：16dp horizontal
- 前缀：+86，textSecondary色，不可编辑
- 输入文字：textPrimary，16sp
- hint文字：textHint，16sp
- 前缀与手机号之间间距：4dp

**状态**：
| 状态 | 边框色 | 说明 |
|------|--------|------|
| 默认 | #E0E0E0 | 未输入 |
| 聚焦 | primary (#8BC34A) | 正在输入 |
| 错误 | #F44336 | 格式错误，显示错误提示 |

### 2.3 验证码区域

```
┌──────────────────────┐  ┌────────────┐
│  请输入验证码        │  │  获取验证码 │  ← 按钮
└──────────────────────┘  └────────────┘
```

**验证码输入框规范**：
- 容器：白色背景，1.5dp边框（#E0E0E0），圆角12dp
- 高度：48dp
- 宽度：flex 1（占满剩余空间）
- 最多6位数字

**验证码按钮规范**：
- 宽度：96dp
- 高度：48dp（与输入框对齐）
- 背景：primaryLight (#C5E8A8)
- 文字：primary (#8BC34A)，14sp Bold
- 圆角：12dp
- 按下态：primary (#8BC34A)，文字变白

**倒计时状态**：
- 按钮文字：59秒（数字每秒递减）
- 背景：#E0E0E0（禁用态）
- 文字：textSecondary
- 60秒后恢复"重新获取"

### 2.4 登录按钮

```
┌──────────────────────────────────────┐
│            登录 / 注册                │
└──────────────────────────────────────┘
```

**规范**：
- 宽度：占满父容器（边距16dp）
- 高度：48dp
- 背景：primary (#8BC34A)
- 文字：#FFFFFF，16sp Bold，圆润字体
- 圆角：12dp
- 上边距：24dp

**状态**：
| 状态 | 背景 | 说明 |
|------|------|------|
| 禁用 | #E0E0E0 | 未填完（手机号或验证码未填写） |
| 正常 | primary | 可点击 |
| Loading | primary + 菊花图标 | 提交中 |

### 2.5 协议勾选

```
┌──────────────────────────────────────┐
│  ☐  我已阅读并同意《用户协议》       │
│      《隐私政策》                     │
└──────────────────────────────────────┘
```

**规范**：
- Checkbox：自定义样式，24×24dp，选中时 primary 色
- 文字：textSecondary，14sp
- 协议文字：primary 色，可点击跳转
- 上边距：16dp
- 居中对齐

### 2.6 底部提示

```
         ─────────────────
         还没有账号？登录即注册
```

**规范**：
- 分隔线：1dp，#E0E0E0，宽度60%
- 文字：textHint，14sp
- 下边距：safeArea + 16dp

## 四、背景设计

### 方案A：纯色背景（推荐）
- 背景色：bg (#F5F5DC)
- 简洁，不干扰表单

### 方案B：趣趣剪影背景
- 背景：bg色
- 底部：趣趣IP淡色剪影（透明度10-15%）
- 方向：趣趣向右走，呼应"学习成长"

### 方案C：淡色渐变
- 背景：LinearGradient
  - 从 #F5F5DC（顶部）
  - 到 #E8F5E9（底部，浅绿）
- 轻微的品牌氛围感

**推荐方案A**（简洁）或方案B（稍带品牌感）

## 五、错误状态处理

### 5.1 手机号格式错误

```
┌──────────────────────────────────────┐
│  请输入手机号                        │ ← 输入框边框变红
│  请输入正确的手机号                  │ ← 错误提示，textCaption，红色
└──────────────────────────────────────┘
```

### 5.2 验证码错误

```
┌──────────────────────────────────────┐
│  123456                              │ ← 输入框
│  验证码错误，请重新输入              │ ← 错误提示
└──────────────────────────────────────┘
```

### 5.3 网络错误

- Toast提示："网络连接失败，请检查网络"
- 按钮恢复可点击状态

### 5.4 服务器错误

- Toast提示："服务异常，请稍后重试"
- 按钮恢复可点击状态
