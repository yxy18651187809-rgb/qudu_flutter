## 一、主角色设计

### 小猫咪咪（主角）

#### 1.1 外观特征
**ASCII art 示意图**：
```
    OO    ← 大圆眼，绿色（#4CAF50）
   /||\   ← 耳朵（橘色，尖尖的）
    ||    ← 头部（圆形，橘色）
   (  )   ← 身体（圆润，穿红色小背心#F44336）
    /\    ← 脚（短小，白色）
   ~  ~   ← 尾巴（翘起来，橘色条纹）
```

**详细设计规范**：
- **头身比**：1:1.5（Q版萌系标准）
- **头部**：圆形，占身体比例较大，橘色毛发（#FF9800）
- **眼睛**：大圆眼，绿色（#4CAF50），高光在左上角
- **耳朵**：尖尖的，内侧粉色（#FFC0CB）
- **条纹**：背部有深橘色条纹（#E65100）
- **衣服**：红色小背心（#F44336），Simple设计
- **表情**：活泼、好奇、专注（根据场景变化）

## 二、配角设计（自动推断）

## 三、QuQu IP定位

### 3.1 外观特征（固定）
**ASCII art 示意图**：
```
    ★★    ← 星星眼（QuQu标志性特征）
   /||\   ← 耳朵
    QQ    ← 身体（圆润的Q版造型）
   (  )   ← 肚子上有"Qu"字母
    /\    ← 脚
```

**配色方案**（固定）：
- 主色：天空蓝（#87CEEB）
- 辅色：云朵白（#FFFFFF）
- 装饰色：阳光黄（#FFD700）

### 3.2 出现规则（默认规则#2）
- **出现位置**：第10页（末尾页）← **注意：L1-12有12页，QuQu应在P12出现**
- **固定台词**："真棒！"
- **表情**：开心竖大拇指
- **动作**：从画面右侧跳出，双手竖大拇指

### 3.3 使用示例（P12）
```
+----------------------------------+
|                P12               |
|                                  |
|    咪咪："我钓到大鱼了！"        |
|    妈妈："你有耐心，真棒！"     |
|                                  |
|    QuQu：★★                     |
|         "真棒！" ← 气泡框       |
|         👍👍                     |
|                                  |
+----------------------------------+
```

**调整说明**：L1-12有12页（超出默认10页），QuQu IP应在P12出现（末尾页）。

## 五、设计规范总结

### 5.1 必须严格遵守
- ✅ 头身比=1:1.5（Q版萌系）
- ✅ 莫兰迪色系（低饱和度、高级感）
- ✅ QuQu IP在P12出现，台词="真棒！"（调整：因L1-12有12页）
- ✅ 新字高亮用黄色圆角字卡

### 5.2 可以灵活调整
- ⚠️ 具体姿势可以根据分镜需要微调
- ⚠️ 背景细节可以适当增加（但不能喧宾夺主）
- ⚠️ 表情可以叠加（如：开心+鼓励）

### 5.3 禁止事项
- ❌ 不能使用高饱和度颜色（荧光色、纯色）
- ❌ 不能改变头身比（不能画成写实风格）
- ❌ QuQu IP不能在非末尾页出现（除非故事情节特殊）
