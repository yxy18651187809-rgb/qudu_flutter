## 一、页面结构

```
┌──────────────────────────────────────┐
│   [进度条 0% ▓░░░░░░░░]          │ ← 顶部进度条（自动隐藏）
│                                    │
│                                    │
│         ┌──────────────┐           │
│         │              │           │
│         │   绘本页面   │           │ ← PageView 全屏翻页
│         │   (图片+文字) │           │
│         │              │           │
│         └──────────────┘           │
│                                    │
│                                    │
│  [←上一页]              [下一页→]  │ ← 底部导航（自动隐藏）
│  [目录]                            │
└──────────────────────────────────────┘
```

**交互逻辑**：
- 点击屏幕中央 → 显示/隐藏控制栏（顶部进度条 + 底部导航）
- 左右滑动 → 翻页（PageView 原生支持）
- 控制栏 3秒无操作 → 自动隐藏

## 二、区域详解

### 2.1 阅读器主界面（全屏PageView）

```
┌──────────────────────────────────────┐
│                                    │
│         ┌──────────────┐           │
│         │  📖 绘本页   │           │ ← 单页内容
│         │              │           │    - 图片（可选）
│         │  "今天早上，  │           │    - 文字内容
│         │   天气很好。" │           │    - 新字高亮
│         │              │           │
│         └──────────────┘           │
│                                    │
└──────────────────────────────────────┘
```

**规范**：
- 页面容器：全屏 PageView，水平翻页
- 翻页动画：Cubic easing，350ms
- 页面边距：24dp（文字内容区）
- 背景色：bg (`#F5F5DC`)，温暖米白

**页面组成**：
| 元素 | 说明 |
|------|------|
| 图片区（可选） | 绘本金页插画，最大高度 400dp |
| 文字区 | 绘本文字内容，字号 24sp，行高 1.8 |
| 新字标记 | 新字高亮 + 气泡提示 |

---

### 2.2 新字高亮样式

```
文字示例：
"今天早上，天气很  [好]  。"

新字 "好" 的显示效果：
┌─────────────────────┐
│  新字文本 "好"      │ ← 文字颜色：white
│  (字号 24sp Bold)  │
├─────────────────────┤
│  💡 新字气泡       │ ← 气泡背景：newWord (`#FF7043`)
│  "hǎo - 好"        │ ← 气泡文字：white，14sp
│  "意思是 good"      │
└─────────────────────┘
```

**新字高亮规范**：
| 状态 | 样式 |
|------|------|
| 默认 | 文字颜色 `newWord` (`#FF7043`)，背景高亮 `newWordBg` (`#FFF3E0`) |
| 点击 | 弹出气泡，显示拼音 + 释义 |
| 已掌握 | 文字颜色恢复 `textPrimary`，无背景高亮 |

**气泡样式**：
- 背景色：newWord (`#FF7043`)
- 圆角：12dp
- 内边距：12dp
- 箭头：指向新字（下方居中）
- 阴影：0 2px 8px rgba(0,0,0,0.15)

**动画**：
- 显示：fadeIn + scale (300ms)
- 隐藏：点击其他区域 → fadeOut (200ms)

### 2.3 顶部进度条

```
┌──────────────────────────────────────┐
│  ┌────────────────────────────────┐ │
│  │ ▓▓▓░░░░░░░░░░░░░░░░░░░░ │ │ ← 进度条
│  └────────────────────────────────┘ │
│  第 3 页 / 共 12 页               │ ← 页码指示
└──────────────────────────────────────┘
```

**规范**：
- 容器高度：48dp
- 进度条高度：6dp
- 进度条圆角：3dp
- 已完成颜色：primary (`#8BC34A`)
- 未完成颜色：primaryLight (`#C5E1A5`)
- 页码文字：textSecondary，14sp
- 上边距：safeArea + 8dp
- 左右边距：24dp

**隐藏状态**：
- 透明度：0（animated，300ms）
- 点击屏幕中央 → 显示（透明度 1）

### 2.4 底部导航按钮

```
┌──────────────────────────────────────┐
│                                    │
│  ┌────┐      ┌──────────┐         │
│  │ ←  │      │ 下一页 → │         │ ← 翻页按钮
│  │ 上一页│    │          │         │
│  └────┘      └──────────┘         │
│                                    │
│  ┌──────────────────────────┐     │
│  │  📑 目录                 │     │ ← 目录按钮
│  └──────────────────────────┘     │
└──────────────────────────────────────┘
```

**上一页/下一页按钮规范**：
- 宽度：120dp
- 高度：48dp
- 背景：primary (`#8BC34A`)，透明度 80%
- 文字：white，16sp
- 圆角：24dp（胶囊形）
- 位置：底部 100dp 处，左右分布

**禁用状态**：
- 第一页：← 上一页 按钮隐藏
- 最后一页：下一页 → 按钮变为 "完成阅读 ✓"

**目录按钮规范**：
- 宽度：占满（边距 24dp）
- 高度：48dp
- 背景：white，1.5dp 边框 (`#E0E0E0`)
- 文字：textPrimary，16sp
- 图标：📑 (或 `Icons.menu_book`)
- 圆角：12dp
- 位置：底部 24dp 处（safeArea 上方）

**点击目录**：
- 弹出底部抽屉 (BottomSheet)
- 显示所有页面缩略图（或页码列表）
- 点击某页 → 跳转到该页

## 六、交互动画

### 6.1 翻页动画

```dart
// PageView 翻页
duration: 350ms
curve: Curves.easeInOutCubic

// 页面内容淡入
AnimationController: 300ms
fadeAnimation: CurvedAnimation(easeInOut)
```

### 6.2 控制栏显示/隐藏

```dart
// 点击屏幕中央
_showControls = !_showControls

// 动画
AnimatedOpacity: 300ms
fade: _showControls ? 1.0 : 0.0

// 自动隐藏
Timer: 3秒无操作 → 隐藏
```

### 6.3 新字气泡动画

```dart
// 点击新字
显示：ScaleTransition + FadeTransition
  缩放：0.8 → 1.0
  透明度：0.0 → 1.0
  时长：300ms

// 点击其他区域
隐藏：FadeTransition
  透明度：1.0 → 0.0
  时长：200ms
```
