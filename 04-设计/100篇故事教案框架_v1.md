## 二、教案框架模板

每篇故事的完整教案包含以下模块：

### 2.1 故事基本信息

```yaml
故事编号: L1-001
故事名称: 《故事标题》
级别: L1（启蒙级）
目标年龄段: 5-6岁
页数: 10-12页
总字数: 100-150字
新字数量: 15-20字
故事类型: [认知类/情感类/行为类/科普类]
主题关键词: [3-5个关键词]
创作状态: [待创作/初稿/审核中/已完成]
```

### 2.2 教育目标

```yaml
【认知目标】
- 认识X个新汉字：字1、字2、字3...
- 理解[主题概念]：如"身体部位"、"四季变化"
- 建立[阅读习惯]：从左到右、从上到下

【情感目标】
- 体验[情感]：如"自我认同"、"关爱他人"
- 培养[态度]：如"好奇心"、"分享意识"

【能力目标】
- 能够[行为]：如"说出身体部位名称"
- 学会[技能]：如"观察图片理解故事"
```

### 2.3 新字表（标准化格式）

| 序号 | 汉字 | 拼音 | 笔画 | 部首 | 组词 | 难度 |
|:---:|:---:|:---:|:---:|:---:|:---|:---:|
| 1 | X | xīng | 3 | 日 | 星星、星空 | ⭐ |
| ... | ... | ... | ... | ... | ... | ... |

**新字选取原则**：
- 笔画数符合级别标准（L1: 1-7画，L2: 1-10画）
- 优先选择象形字、指事字
- 贴近故事主题和儿童生活
- 考虑与其他故事的覆盖率均衡

### 2.4 故事脚本模板

```markdown
## 【封面】

**画面描述**：
[具体画面内容，包括人物、场景、色彩]

**新字呈现**：
- [新字1]：位置+样式（如右上角黄色气泡）
- [新字2]：

**插图风格要求**：
- 色调：
- 氛围：
- 趣趣（IP形象）：

---

## 【第1页】

**页面标题**：[标题]

**故事文案**：
> [完整文案，5-15字]
> 【新字：X、X】

**画面描述**：
[具体场景描述]

**分镜布局**：
```
┌─────────────────────────────────────┐
│                                     │
│         [画面主要内容]              │
│                                     │
│                                     │
│  ┌─────────┐                        │
│  │【新字】 │  ← 黄色气泡标注         │
│  └─────────┘                        │
└─────────────────────────────────────┘
```

**插图设计要点**：
- 人物表情：
- 场景细节：
- 色彩搭配：
- 新字高亮方式：

---
```

### 2.5 插图内容设计规范

```yaml
【视觉风格】
- 画风：可爱插画风，参考日本绘本风格
- 线条：圆润流畅，避免尖锐棱角
- 上色：明亮温暖，饱和度适中

【角色设计】
- 主角：统一使用IP形象（趣趣）+ 故事角色
- 配角：简洁可爱，辨识度高
- 表情：夸张适度，符合儿童审美

【场景设计】
- 背景：简洁留白，突出主体
- 色彩：配合故事氛围
- 细节：可添加小彩蛋增加趣味

【新字呈现】
- 位置：页面固定位置（如右下角）
- 样式：黄色气泡+白色汉字
- 大小：适中，不喧宾夺主

【趣趣出场规则】
- 封面：必须出场（引导阅读）
- 内页：每2-3页出场一次
- 尾页：总结回顾时出场
```

## 三、联动机制

### 3.1 插画师 × 教研员 协作流程

```
┌──────────────┐    ┌──────────────┐    ┌──────────────┐
│   教研员     │    │   协作平台   │    │   插画师     │
│  (内容设计)  │◄──►│  (教案框架)  │◄──►│  (插图设计)  │
└──────────────┘    └──────────────┘    └──────────────┘
      │                   │                   │
      ▼                   ▼                   ▼
  1.制定主题          2.确认教案          3.分镜脚本
  2.编写文案          3.审核字表          4.插图设计
  3.审核字表          4.提出建议          5.上色规范
  4.验收插图          5.确认定稿
```

### 3.2 任务分配表

| 角色 | 负责模块 | 产出物 | 交付时间 |
|:---:|:---|:---|:---:|
| **教研员** | 主题规划、文案编写、新字表、教育目标 | 故事脚本v1.0 | 每个故事3-5天 |
| **插画师** | 分镜脚本、插图设计、上色规范 | 分镜线稿+上色版 | 每个故事5-7天 |
| **教研员审核** | 内容准确性、字表合规性、教育价值 | 审核报告 | 2天内 |

### 3.3 质量标准

| 检查项 | 标准 | 责任方 |
|:---|:---|:---:|
| 新字数 | L1: 15-20字/L2: 20-25字/L3+: 25-30字 | 教研员 |
| 笔画合规 | L1≤7画/L2≤10画/L3+≤12画 | 教研员 |
| 字表重复率 | 同级别内新字重复率 < 20% | 教研员 |
| 画面与文案匹配 | 分镜与文案100%对应 | 插画师 |
| 新字呈现位置 | 固定位置，统一样式 | 插画师 |
| 色彩规范 | 符合IP形象规范 | 插画师 |

## 六、附录

### 6.1 趣趣（IP形象）出场指南

```yaml
【封面页】
- 必须出场
- 姿态：站立欢迎状，引导阅读
- 位置：角落或底部

【内页】
- 出场频率：每2-3页1次
- 姿态：根据故事内容变化
- 作用：陪同主角、引导观察、情感共鸣

【尾页/总结页】
- 必须出场
- 姿态：挥手告别/击掌庆祝
- 作用：总结回顾、鼓励互动
```
