## 一、版本目标

v1.0 完成了 MVP 核心闭环（登录→建档→测评→绘本→识字）。v1.1 的核心目标是：

1. **内容扩展**：L2-L5 教案（共200篇）上线，覆盖5-12岁全年龄段
2. **家长端**：学习报告 + 进度监控，提升家长付费意愿
3. **支付体系**：VIP 会员系统，实现商业化闭环
4. **社交传播**：分享报告海报 + 邀请有礼，降低获客成本

## 二、新增功能清单

### 2.1 家长端学习报告（新功能）

| 功能点 | 说明 | 优先级 |
|--------|------|--------|
| 周报生成 | 每周自动生成学习周报（识字量增长+阅读时长+绘本完成数） | P0 |
| 报告推送 | 微信模板消息推送 / APP 内通知 | P0 |
| 报告详情页 | 图表展示（折线图+柱状图），支持分享海报到朋友圈 | P0 |

| 同龄对比 | 匿名化的同龄儿童识字量对比（optional） | P2 |

#### 报告模板（示例）

```

✅ 识字量：+12字（累计 68字）
✅ 绘本阅读：5本（完成率 83%）
✅ 学习时长：42分钟
⚠️ 需复习：大、小、上（3字）

[查看详细报告]
```

### 2.3 微信登录（新功能）

| 功能点 | 说明 | 优先级 |
|--------|------|--------|
| 微信授权登录 | 调用微信开放平台 SDK，获取 unionid | P0 |
| 手机号绑定 | 微信登录后引导绑定手机号（用于找回账号） | P0 |
| 账号合并 | 同一手机号的历史账号与微信账号合并 | P1 |
| 快速注册 | 微信登录 + 创建儿童档案，一步完成 | P0 |

#### 业务规则

- 微信登录与手机号登录**互斥但可绑定**
- 微信 unionid 作为唯一标识，一个微信只能绑定一个家长账号
- 解绑微信需在「设置」中操作，需验证手机号

## 四、用户流程更新

### 4.1 家长端新流程

```
打开APP → 底部Tab「我的」→ 点击「学习报告」
    → 查看周报/月报
    → 点击「分享」→ 生成海报 → 分享到微信
```

### 4.2 微信登录新流程

```
打开APP → 登录页点击「微信登录」
    → 跳转到微信授权
    → 首次使用：引导绑定手机号 + 创建儿童档案
    → 非首次：直接登录进入首页
```

### 4.3 支付新流程

```
阅读绘本 → 遇到「VIP专属」绘本书籍
    → 点击「开通VIP」
    → 选择会员类型
    → 微信支付
    → 支付成功，自动解锁内容
```
