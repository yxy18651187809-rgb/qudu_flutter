## 一、平台策略

### 1.1 目标平台

| 平台 | 最低版本 | 支持设备 | 适配策略 |
|------|---------|---------|---------|
| **iOS** | iOS 14+ | iPhone 8+ / iPad | iOS 14+ 覆盖 99.2% 活跃设备 |
| **Android** | API 26+ (Android 8.0) | 主流设备 | 覆盖 95%+ 国内市场 |

### 1.2 跨平台框架选择

**框架**: Flutter 3.19.6 + Dart 3.3.4（继续使用现有栈）

| 维度 | Flutter 优势 | 与项目匹配度 |
|------|------------|-----------|
| 性能 | Skia 自渲染引擎，接近原生性能 | ✅ 游戏化场景需要 60fps 动画 |
| UI 一致性 | 统一组件，减少双端差异 | ✅ 5-12 岁儿童需要一致视觉体验 |
| 开发效率 | 一套代码双端交付 | ✅ 小团队资源优化 |
| 生态 | 丰富插件库（fluwx、audioplayers 等） | ✅ 已集成微信登录、音频播放 |
| 包体积 | 中等（可优化至 25MB 内） | ✅ 儿童教育 App 可接受 |

> **决策**: 继续采用 Flutter，但需强化平台特定优化（iOS/Android 各一套构建配置和原生代码）。

## 二、跨平台架构设计

### 2.1 整体架构

```
┌─────────────────────────────────────────────────────┐
│                    呈现层 (Presentation)               │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐  │
│  │  页面 (Pages)  │  │  状态 (Bloc)   │  │  UI 组件库    │  │
│  └─────────────┘  └─────────────┘  └─────────────┘  │
├─────────────────────────────────────────────────────┤
│                    业务层 (Domain)                     │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐  │
│  │  Use Cases   │  │  Entities    │  │  Repositories│  │
│  └─────────────┘  └─────────────┘  └─────────────┘  │
├─────────────────────────────────────────────────────┤
│                    数据层 (Data)                       │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐  │
│  │  API Client  │  │  Local DB    │  │  Cache/Assets│  │
│  └─────────────┘  └─────────────┘  └─────────────┘  │
├─────────────────────────────────────────────────────┤
│                    平台层 (Platform)                    │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐  │
│  │ iOS 原生桥接  │  │ Android 原生桥接│  │ 插件管理     │  │
│  └─────────────┘  └─────────────┘  └─────────────┘  │
└─────────────────────────────────────────────────────┘
```

### 2.2 分层职责

| 层级 | 职责 | 代表文件/目录 |
|------|------|-------------|
| **Presentation** | 页面渲染、状态管理、动画 | `presentation/pages/`, `presentation/blocs/`, `presentation/widgets/` |
| **Domain** | 业务逻辑、数据映射 | `domain/use_cases/`, `domain/models/`, `domain/repositories/` |
| **Data** | 网络请求、本地存储、文件IO | `data/network/`, `data/local/`, `data/cache/` |
| **Platform** | 平台原生能力桥接、设备特性 | `ios/`, `android/`, `plugins/` |

### 2.3 依赖方向

```
Presentation → Domain ← Data → Platform

规则：
1. 上层依赖下层，下层不可依赖上层
2. Domain 层不依赖任何平台特定代码（Flutter, iOS, Android）
3. 依赖注入通过 ServiceLocator 解耦
```

## 四、性能优化策略

### 4.1 启动优化

**目标**: 冷启动 < 2.5 秒（iOS）/ < 3 秒（Android）

```dart
// 启动优化策略
class App extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      // 预加载关键资源
      builder: (context, child) => FutureBuilder(
        future: _preloadCriticalResources(),
        builder: (context, snapshot) {
          if (snapshot.connectionState == ConnectionState.done) {
            return child!;
          }
          return SplashScreen(); // 原生启动屏
        },
      ),
    );
  }
  
  Future<void> _preloadCriticalResources() async {
    // 并行初始化，不阻塞 UI
    await Future.wait([
      ServiceLocator.init(),          // DI 容器初始化
      ApiClient.instance.init(),       // 网络层初始化
      FlutterSecureStorage().read(key: 'token'), // 检查登录状态
      // 预加载首页需要的图片缓存
      precacheImage(AssetImage('assets/images/logo.png'), context),
    ]);
  }
}
```

### 4.2 内存管理

**目标**: 运行内存 < 80MB（中低端设备）

### 4.4 网络优化

```dart
// 网络层优化配置
class ApiClient {
  static Dio createDio() {
    return Dio(BaseOptions(
      baseUrl: 'https://api.ziqu.com',
      connectTimeout: Duration(seconds: 10),
      receiveTimeout: Duration(seconds: 30),
      sendTimeout: Duration(seconds: 10),
    ))
    // 缓存策略
    ..interceptors.add(DioCacheInterceptor(
      options: CacheOptions(
        store: MemCacheStore(),
        policy: CachePolicy.request,
        hitCacheOnErrorExcept: [401, 403],
        maxStale: const Duration(days: 7),
      ),
    ))
    // 请求队列（401 刷新 Token 时不重发）
    ..interceptors.add(QueuedInterceptor());
  }
}
```

| 策略 | 实现 | 效果 |
|------|------|------|
| HTTP/2 | 服务器端启用 | 减少连接数，提升并发 |
| Gzip 压缩 | 服务器响应自动 | 减少 60-70% 传输量 |
| 图片 CDN | 阿里云/腾讯云 CDN | 加速静态资源加载 |
| 请求合并 | 批量接口设计 | 减少网络往返 |
| 离线优先 | 本地缓存 + 增量同步 | 弱网可用 |

### 5.2 离线数据架构

```dart
// 离线数据管理
class OfflineDataManager {
  final Database _db; // sqflite
  final SyncQueue _syncQueue; // 待同步队列
  
  // 学习记录本地存储
  Future<void> saveLearningRecord(LearningRecord record) async {
    await _db.insert('learning_records', record.toJson());
    await _syncQueue.enqueue(record); // 加入同步队列
  }
  
  // 网络恢复时批量同步
  Future<void> syncPendingRecords() async {
    final pending = await _syncQueue.getPending();
    for (final batch in pending.chunked(50)) {
      try {
        await ApiClient().post('/learning-records/batch', data: batch);
        await _syncQueue.markSynced(batch);
      } catch (e) {
        break; // 失败保留队列，下次重试
      }
    }
  }
  
  // 绘本资源预下载
  Future<void> prefetchBookResources(String bookId) async {
    final book = await _db.query('books', where: 'id = ?', whereArgs: [bookId]);
    for (final page in book['pages']) {
      await DefaultCacheManager().getSingleFile(page['imageUrl']);
      await DefaultCacheManager().getSingleFile(page['audioUrl']);
    }
  }
}
```

class PrivacyConsentPage extends StatelessWidget {
  // 1. 首次启动显示隐私协议
  // 2. 用户同意后才初始化第三方 SDK（微信、Firebase）

  }

    await Fluwx().registerApi(appId: 'wx...', doOnIOS: true, doOnAndroid: true);
    // Firebase（推送、统计）

  }
}
