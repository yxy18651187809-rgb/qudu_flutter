## 二、反馈表单设计（APP 内）

### 2.1 表单字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 用户身份 | 单选 | 是 | 家长 / 孩子（弹出年龄确认） |
| 反馈类型 | 单选 | 是 | Bug / 功能建议 / 内容建议 / 付费咨询 / 其他 |
| 发生页面 | 下拉选择 | 是 | 登录页 / 首页 / 识字页 / 书架 / 阅读器 / 测评 / 我的 |
| 问题描述 | 多行文本 | 是 | 50-500 字 |
| 截图上传 | 图片 | 否 | 最多 3 张 |
| 联系方式 | 手机号 / 微信 | 否 | 方便后续回访 |
| 是否愿意回访 | 单选 | 是 | 是 / 否 |

### 2.2 表单 UI 文案

```

   ○ 家长   ○ 孩子

   [下拉选择]

   ○ 是   ○ 否

[提交反馈]
```

## 三、反馈处理流程

```
用户提交反馈
    ↓
自动分类（AI 辅助打标签）
    ↓
运营每日查看（9:00 前）
    ↓
按优先级分类（P0/P1/P2）
    ↓
分配给对应负责人
    ↓
处理并回复用户（≤ 48 小时）
    ↓
记录到反馈汇总表
    ↓
月度复盘（每月 1 日）
```

## 四、优先级分类标准

| 优先级 | 定义 | 响应时间 | 示例 |
|---------|------|---------|------|
| **P0 紧急** | 影响核心功能、数据丢失、付费失败 | ≤ 4 小时 | 无法登录、付费失败、数据丢失 |
| **P1 重要** | 功能异常但不影响核心流程 | ≤ 24 小时 | 绘本无法翻页、测评提交失败 |
| **P2 一般** | 体验优化、内容建议 | ≤ 72 小时 | 字体太小、建议增加某功能 |
| **P3 低优** | 边缘场景、个别用户需求 | 下个版本规划 | 建议增加某方言发音 |

## 七、用户访谈提纲（1v1）

### 7.1 访谈目标

- 了解用户真实使用场景
- 发现未被表达的痛点
- 验证功能优先级

### 7.2 访谈问题清单

```
【开场】
1. 您好，感谢您参加字趣阅读的访谈。请问您方便聊多久？
2. 您家孩子今年几岁？使用字趣阅读多久了？

【使用场景】
3. 孩子一般什么时候使用字趣阅读？（放学后/周末/睡前）
4. 一般一次用多久？您会陪同吗？
5. 孩子最喜欢哪个功能？为什么？

【痛点挖掘】
6. 使用过程中有没有让您觉得不方便的地方？
7. 孩子有没有说过「不想用了」或「这个不好玩」？
8. 您觉得哪部分对孩子帮助最大？哪部分帮助最小？

【付费意愿】
9. 您对现在的免费功能满意吗？
10. 如果开通 VIP 可以解锁全部绘本，您愿意付费吗？价格预期是多少？
11. 您更倾向于月卡、季卡还是年卡？

【竞品对比】
12. 您还用过哪些识字类产品？（洪恩/悟空/其他）
13. 相比之下，您觉得字趣阅读的优势是什么？不足是什么？

【关闭】
14. 您希望我们接下来优先改进哪方面？
15. 是否愿意后续继续参与访谈？
```
