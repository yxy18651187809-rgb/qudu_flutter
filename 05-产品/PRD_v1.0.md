## 一、产品概述

### 1.1 产品定位

字趣阅读是一款面向 **5-12岁儿童** 的 AI 识字阅读 APP。通过**分级绘本 + AI 识字测评 + 智能推荐**，帮助儿童在趣味阅读中高效识字，同时为家长提供学习数据洞察。

### 1.2 目标用户

| 用户角色 | 画像 | 核心诉求 |
|---------|------|---------|
| **儿童（5-12岁）** | 学前及小学阶段，对识字有需求 | 有趣、不枯燥、能自主阅读、有成就感 |
| **家长（25-40岁）** | 一二线城市，重视教育投入 | 科学前有效识字、了解孩子进度、省心省力 |

### 1.3 核心价值主张

**对孩子**：每一本绘本都是一场小小的冒险，阅读就像玩游戏一样有趣。  
**对家长**：AI 精准测评识字量，科学推荐阅读内容，学习进度一目了然。

### 1.4 商业模式

- **免费层**：识字测评 + 5本免费绘本 + 生字本基础功能
- **付费层**：VIP会员解锁全部分级绘本（月卡/季卡/年卡）
- **扩展**：后续可拓展单本购买、实体绘本周边

### 4.1 用户注册/登录

#### 4.1.1 流程图

```
打开APP → 手机号输入 → 获取验证码 → 验证登录
                            ↓
                     新用户：创建档案
                     老用户：进入首页
```

#### 4.1.2 功能说明

| 字段 | 类型 | 说明 |
|------|------|------|
| 手机号 | 输入框 | 11位手机号，前端格式校验 |

- 注册即自动创建家长账号，需补充儿童档案
- 登录 Token 有效期 30 天，过期自动刷新

#### 4.1.4 交互要点

- 进入 APP 即显示登录页，无引导页（MVP 简化）
- 验证码输入框自动聚焦
- 登录成功后，如无儿童档案，自动跳转「创建档案」

### 4.3 AI 识字测评（核心功能）

#### 4.3.1 概述

识字测评是产品的核心入口功能，通过自适应测评算法精准定位儿童的识字量等级，为后续绘本推荐提供数据基础。

#### 4.3.2 流程图

```
测评入口 → 引导说明（1页）→ 开始测评
    → 逐题展示汉字 → 选择「认识/不认识」
    → 自适应调整题目难度 → 达到终止条件
    → 测评结果页（识字量+等级+推荐）
```

#### 4.3.3 测评引导页

| 元素 | 内容 |
|------|------|
| 标题 | 来测测你认识多少字吧！ |
| 说明 | 你会看到一些汉字，认识的点「✓」，不认识的点「✗」 |
| 预计时长 | 约 3-5 分钟 |
| 按钮 | 「开始测评」 |

#### 4.3.4 测评题目展示

**界面布局**：

```
┌──────────────────────────────────┐
│  ✕ 退出              3/30  进度  │
│──────────────────────────────────│
│                                  │
│                                  │
│            山                     │  ← 中心大字，字号96px
│                                  │
│         (shān)                   │  ← 可选拼音提示
│                                  │
│──────────────────────────────────│
│                                  │
│     [ ✓ 认识 ]    [ ✗ 不认识 ]   │  ← 底部双按钮
│                                  │
└──────────────────────────────────┘
```

**交互规则**：

- 汉字居中展示，字号 96px
- 点击「认识」或「不认识」后，自动切换下一题，间隔 0.3 秒
- 不提供拼音提示（MVP 版本，保持测评准确性）
- 点击退出弹窗确认：「确定要退出测评吗？当前进度将不会保存」
- 每题展示后开始计时，超过 8 秒未操作视为「不认识」

#### 4.3.5 自适应测评算法

**设计原则**：基于二分查找思想，用最少题目精准定位识字水平。

**题库结构**：

```
题库按等级分层：
L1 (300字) → L2 (600字) → L3 (1000字) → L4 (1500字) → L5 (2500字)
```

**算法流程**：

```
1. 初始出题：从 L3 中随机抽取 5 题（中间难度探底）
2. 根据前 5 题正确率判定方向：
   - 正确率 ≥ 80% → 向上探索（L4→L5）
   - 正确率 ≤ 40% → 向下探索（L2→L1）
   - 40% < 正确率 < 80% → 当前等级附近细测
3. 细测阶段：在目标等级±1范围内继续抽题
4. 终止条件（满足任一）：
   - 总题数达到 30 题
   - 连续 5 题错误（下探到底）
   - 连续 5 题正确（上探到顶）
   - 置信度达到 85% 以上
5. 结果计算：
   - 识字量 = 正确字数 × (该等级字库总量 / 测试字数)
   - 等级 = 对应识字量落地的等级区间
```

**等级判定标准**：

| 识字量 | 判定等级 | 描述 |
|--------|---------|------|
| 0-300 | L1 | 启蒙级，需要从最基础的汉字开始 |
| 301-600 | L2 | 起步级，已有基础，可以读简单绘本 |
| 601-1000 | L3 | 发展级，可以自主阅读短篇 |
| 1001-1500 | L4 | 提升级，阅读能力较强 |
| 1501+ | L5 | 进阶级，可以阅读长篇故事 |

**推荐逻辑**：

```

  2. 计算每本绘本的「新字数」（绘本生字 - 已识字 = 新字数）

  4. 优先未读过的绘本
  5. 按推荐分数降序排列
输出：推荐绘本列表
```

| 新字数 | 「新字 5 个」标签 |
| 阅读状态 | 未读 / 阅读中 / 已读完 |
| 免费标签 | 免费 / VIP |

**生字高亮规则**：

| 字类型 | 样式 | 说明 |
|--------|------|------|
| 新字（首次出现） | **加粗** + 黄色底色 + 拼音 | 在文字上方显示拼音 |
| 新字（重复出现） | **加粗** + 黄色底色 | 不显示拼音 |
| 复习字 | 正常显示 | 已学过的字不做特殊标记 |
| 超纲字 | 正常显示 | 超出当前等级的字 |

**点读交互**：

- **点击生字**：播放该字的发音（TTS），弹出字卡浮层
  - 浮层内容：汉字（大号）+ 拼音 + 组词 1-2 个
  - 浮层 3 秒后自动消失，或点击其他区域关闭
- **点击非生字文字**：播放整句话的朗读
- **点击插画区域**：播放整页文字的朗读（全页伴读）
- **左滑/点击右箭头**：下一页（带翻页动画）
- **右滑/点击左箭头**：上一页

**翻页动画**：

- 采用仿真翻页效果（Flutter `page_turn` 插件）
- 动画时长 0.4 秒
- 翻页时自动停止当前音频播放

**菜单功能（右上角 ⋮）**：

- 自动播放（逐页自动翻页+朗读）
- 关闭自动播放
- 退出阅读

#### 4.4.5 阅读后测评

**概述**：每本绘本阅读完成后，提供轻量级测评巩固所学。

**测评形式**（MVP 简化版）：

| 题型 | 说明 | 数量 |
|------|------|------|
| 生字认读 | 展示汉字，选择正确拼音 | 3-5 题 |
| 听音选字 | 播放发音，选择对应汉字 | 2-3 题 |
| 图文配对 | 展示图片，选择对应文字 | 1-2 题 |

**题库来源**：

- 从当前绘本的 `new_words` 中抽取
- 另外混入 1-2 个复习字作为干扰项

**业务规则**：

- 每题限时 15 秒，超时视为答错
- 答对给予正向反馈动画（星星特效）
- 答错给予鼓励（「没关系，多读几遍就会了」）
- 答对 1 个汉字记入「已认识」列表
- 测评完成后回到阅读完成页，更新结果

## 六、非功能需求

### 6.1 性能要求

| 指标 | 目标值 | 说明 |
|------|--------|------|
| APP 冷启动 | ≤ 3 秒 | 首屏可交互时间 |
| 页面切换 | ≤ 0.5 秒 | 页面跳转+渲染 |
| 音频播放延迟 | ≤ 200 毫秒 | 点击到开始播放 |
| 绘本加载 | ≤ 2 秒 | 封面+首页内容加载完成 |
| API 响应时间 | ≤ 500 毫秒 | P99 |

### 6.2 兼容性

| 平台 | 最低版本 |
|------|---------|
| iOS | iOS 13.0+ |
| Android | Android 8.0+（API 26） |
| 屏幕适配 | iPhone SE ~ iPad Mini；主流 Android 手机+平板 |

### 6.3 安全与合规

- **儿童隐私保护**：遵守《儿童个人信息网络保护规定》
- 收集数据最小化：仅收集必要的学习行为数据
- 家长授权：注册时即视为家长授权
- 禁止第三方广告追踪 SDK
- 数据传输全链路 HTTPS 加密
- 支持数据导出和账号注销

### 6.4 可用性要求

| 场景 | 要求 |
|------|------|
| 无网络 | 已缓存的绘本可离线阅读，测评需在线 |
| 网络切换 | WiFi/4G 自动切换，无感知 |
| 弱网 | 图片降级加载，音频延迟播放 |
| 中断恢复 | 电话/短信中断后自动恢复阅读位置 |

## 九、风险与应对

| 风险 | 影响 | 概率 | 应对策略 |
|------|------|------|---------|
| 测评算法不准导致推荐偏差 | 高 | 中 | 上线前人工验证 20+ 个样本，持续优化题库 |
| TTS 语音质量不佳影响体验 | 中 | 低 | 评估多个 TTS 方案（讯飞/百度/Edge），选最优 |
| 绘本内容不足导致用户流失 | 高 | 中 | MVP 确保 10 本 L1 绘本质量，内容不过量求精品 |
| 儿童使用时长不可控引发家长顾虑 | 中 | 中 | 内置阅读时长提醒（15 分钟一次），家长端控制 V1.0 补齐 |
| 应用商店审核被拒 | 高 | 低 | 提前研究审核规则，隐私协议完备 |
