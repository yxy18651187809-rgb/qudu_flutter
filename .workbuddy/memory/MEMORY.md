# 字趣阅读 - 长期记忆

## 项目基本信息
- **产品名**：字趣阅读（5-12岁儿童AI识字阅读APP）
- **团队**：运营、教研员、前端负责人、后端负责人、插画师
- **技术栈**：Flutter 3.19.6 + Node.js + MongoDB + Redis
- **当前阶段**：Phase 1 启动期

## 关键经验
- **团队通信不可靠**：send_message 成功仅表示写入邮箱，Agent 实例可能不活跃。重要信息必须同时落地到 `TEAM_STATUS.md` 共享文件
- **邮箱文件可作为备份**：`.workbuddy/teams/{team-id}/inboxes/` 目录下的 JSON 文件包含所有历史消息
- **Agent 重启后邮箱不自动消费**：重启后的新实例需要主动轮询或手动读取邮箱才能获取历史消息
- **紧急加速令需先核实实际进度**：运营发出"三天任务一天完成"的加速令，但插画师实际上大部分已完成。发出紧急令前应先查阅 TEAM_STATUS.md 确认各成员真实状态，避免无效催促
