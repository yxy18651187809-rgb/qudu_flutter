# 字趣阅读 · L1测字题库设计 v1

> **级别**：L1 启蒙级（5-6岁）  
> **覆盖范围**：绘本01-10，共163个独立新字  
> **设计日期**：2026-04-22  
> **对接API**：后端 Assessment Model（3种题型 + 自适应出题）

---

## 一、设计原则

| 原则 | 说明 |
|:---|:---|
| **适龄性** | 5-6岁儿童，题目以图片+语音为主，文字为辅 |
| **渐进性** | 从绘本内新字→绘本间复习字→L1扩展字，逐步推进 |
| **趣味性** | 趣趣IP互动引导，答对有星星奖励，答错有鼓励 |
| **科学性** | 基于遗忘曲线（SM-2算法），优先复习薄弱字 |
| **安全性** | 避免负面反馈，不显示"错误"，用"再试试"替代 |

## 二、题型设计

### 2.1 题型总览

| 题型ID | 题型名称 | 对应后端字段 | 说明 | 适合阶段 |
|:---:|:---|:---:|:---|:---|
| recognize | **看字选图** | `recognize` | 显示汉字，选择对应图片 | 初学 |
| pinyin_match | **听音选字** | `pinyin_match` | 播放拼音/语音，选择正确汉字 | 巩固 |
| meaning_select | **看图选字** | `meaning_select` | 显示图片，选择对应汉字 | 深化 |

### 2.2 题型详细说明

#### 题型1：看字选图（recognize）

**界面**：
```
┌─────────────────────┐
│  趣趣："这是哪个字？"  │
│                     │
│       【 人 】       │  ← 汉字大卡片，可点击听发音
│                     │
│  ┌───┐  ┌───┐      │
│  │🏠 │  │👤 │      │  ← 4个图片选项
│  └───┘  └───┘      │
│  ┌───┐  ┌───┐      │
│  │🌳 │  │🐕 │      │
│  └───┘  └───┘      │
└─────────────────────┘
```

**规则**：
- 4个图片选项，1个正确+3个干扰
- 干扰项策略：同绘本其他新字图 > 同主题字 > 随机字
- 答对：⭐ +1星，趣趣"太棒了！"
- 答错：趣趣"再试试？"，高亮正确答案1.5秒

#### 题型2：听音选字（pinyin_match）

**界面**：
```
┌─────────────────────┐
│  趣趣："找到 rén！"   │
│     🔊 再听一次       │  ← 播放拼音+语音
│                     │
│  ┌───┐  ┌───┐      │
│  │ 人 │  │ 入 │      │  ← 4个汉字选项
│  └───┘  └───┘      │
│  ┌───┐  ┌───┐      │
│  │ 大 │  │ 门 │      │
│  └───┘  └───┘      │
└─────────────────────┘
```

**规则**：
- 4个汉字选项，1个正确+3个干扰
- 干扰项策略：形近字（人/入）> 音近字 > 同绘本字 > 随机字
- 自动播放1次语音，可点击重播

#### 题型3：看图选字（meaning_select）

**界面**：
```
┌─────────────────────┐
│  趣趣："这是什么？"    │
│                     │
│       🌞            │  ← 大图片
│                     │
│  ┌───┐  ┌───┐      │
│  │ 日 │  │ 月 │      │  ← 4个汉字选项
│  └───┘  └───┘      │
│  ┌───┐  ┌───┐      │
│  │ 天 │  │ 星 │      │
│  └───┘  └───┘      │
└─────────────────────┘
```

**规则**：
- 4个汉字选项，1个正确+3个干扰
- 干扰项策略：同主题字（日/月/天/星）> 同绘本字 > 随机字
- 图片需统一风格，与绘本插画一致

## 三、出题策略

### 3.1 测评类型

| 测评类型 | 后端type | 题数 | 触发时机 | 目的 |
|:---|:---:|:---:|:---|:---|
| **初始测评** | `initial` | 20 | 首次使用APP | 估算识字量，定初始级别 |
| **绘本测评** | `review` | 10 | 绘本阅读后 | 检验本绘本新字掌握 |
| **级别测评** | `level_test` | 20 | 完成级别所有绘本后 | 晋级评估 |

### 3.2 自适应出题规则

```
1. 初始测评（20题）：
   - L1核心字219字中随机抽20字
   - 每题1-3种题型随机
   - 根据正确率估算识字量：
     · 正确率 > 80% → 识字量 ≈ (正确数/20) × 219 × 1.2
     · 正确率 50-80% → 识字量 ≈ (正确数/20) × 219
     · 正确率 < 50% → 识字量 ≈ (正确数/20) × 219 × 0.8

2. 绘本测评（10题）：
   - 本绘本新字全部覆盖（优先新字）
   - 复习字2-3个（跨绘本复习）
   - 题型：先recognize（5题）→ meaning_select（3题）→ pinyin_match（2题）

3. 级别测评（20题）：
   - 本级别所有绘本新字中抽15字
   - 复习字5个
   - 题型均匀分配
```

### 3.3 干扰项生成规则

| 优先级 | 策略 | 示例（正确答案：人） |
|:---:|:---|:---|
| 1 | 形近字 | 入、八、大 |
| 2 | 同绘本新字 | 口、手、头 |
| 3 | 同主题字 | 大、小、我 |
| 4 | 音近字 | 认、任 |
| 5 | 随机L1字 | — |

**约束**：干扰项不能与正确答案同音同调（避免歧义）。

## 五、题库数据结构

### 5.1 题目JSON格式

```json
{
  "characterId": "ObjectId",
  "character": "人",
  "questionType": "recognize",
  "options": ["人图片", "口图片", "手图片", "大图片"],
  "correctAnswer": "人图片",

  "bookId": "ObjectId",
  "distractorStrategy": "same_book"
}
```

### 5.2 与后端Assessment Model的映射

| 题库字段 | Assessment字段 | 说明 |
|:---|:---|:---|
| characterId | questions.characterId | 汉字ID |
| character | questions.character | 汉字 |
| questionType | questions.questionType | recognize/pinyin_match/meaning_select |
| options | questions.options | 选项数组 |
| correctAnswer | questions.correctAnswer | 正确答案 |
| — | questions.userAnswer | 用户答案（运行时填入） |
| — | questions.isCorrect | 是否正确（运行时计算） |
| — | questions.responseTime | 响应时间（运行时记录） |

## 六、题库生成脚本计划

> **注意**：题库不由seed.js静态导入，而是由后端测评API动态生成。

### 6.1 动态出题流程

```
1. 前端请求 POST /api/v1/assessments
   - body: { childId, type: 'review', targetLevel: 1, bookId: '...' }
   
2. 后端生成题目：
   a. 查询本绘本 newWords（Book Model）
   b. 查询 L1 字库（Character Model）
   c. 按干扰项策略生成每题 options
   d. 写入 Assessment.questions
   e. 返回 Assessment（含题目）

3. 前端逐题作答：
   - PUT /api/v1/assessments/:id/answer
   - body: { questionIndex, userAnswer, responseTime }
   
4. 后端计算结果：
   - 更新 isCorrect、totalScore、accuracy
   - 调用 SM-2 算法更新学习记录
   - 计算星星/金币奖励
```

### 6.2 干扰项生成服务（待开发）

## 七、质量保障

### 7.1 题目审核清单

- [ ] 每题4个选项，1正确3干扰
- [ ] 干扰项与正确答案不同音同调
- [ ] 图片选项风格统一（与绘本插画一致）
- [ ] 拼音标注使用Unicode声调符号
- [ ] 每本绘本新字100%覆盖
- [ ] 难度分级合理（⭐简单 → ⭐⭐中等 → ⭐⭐⭐挑战）

### 7.2 测试要点

| 测试项 | 预期结果 |
|:---|:---|
| 同一绘本测评两次 | 题目不完全相同（随机性） |
| 答对全部题目 | 正确率100%，⭐奖励 |
| 答错1题 | 趣趣鼓励，正确答案高亮 |
| 中途退出 | status=abandoned，不计算结果 |
| 网络断开 | 本地暂存答案，重连后提交 |
