## 一、差距确认

收到你的对比分析，教研侧逐项确认如下：

### 差距1：bookId 参数缺失

**教研确认**：同意，这是绘本测评场景的必要参数。

| 场景 | 需要bookId | 说明 |
|------|:----------:|------|
| 绘本测评（review + bookId） | ✅ 必须 | 需从 Book.newWords 取本绘本新字出题 |
| 初始测评（initial） | ❌ 不需要 | 从 Character 表按 level 随机抽取 |
| 级别测评（level_test） | ❌ 不需要 | 从本级别所有绘本 newWords 合集抽取 |

**API调整建议**：

```javascript
// POST /api/v1/assessments（startAssessment）
// 新增可选参数：
{
  childId: "ObjectId",    // 必须
  type: "review",         // 必须: initial | review | level_test
  targetLevel: 1,         // 必须
  questionCount: 10,      // 可选，默认20
  bookId: "ObjectId"      // 可选，type=review时必须传
}
```

**Assessment Model 新增字段**：

```javascript
// Assessment.js Schema
{
  bookId: { type: Schema.Types.ObjectId, ref: 'Book' },  // 新增，绘本测评时记录来源绘本
  // ... 其他字段不变
}
```

### 差距2：questionGenerator.js 未实现

**教研确认**：同意，这是 v1.1 核心交付。

**教研侧需求**：题库设计v1的 §6.2 已规划了 `questionGenerator.js` 的接口，核心功能点：

1. **generateDistractors(correctChar, strategy, count=3)**
   - 5级干扰项策略按优先级fallback：形近字 > 同绘本新字 > 同主题字 > 音近字 > 随机L1字
   - 约束：干扰项不能与正确答案同音同调
   - 主题映射表（教研提供）：见下方

2. **generateBookQuestions(bookId, questionCount=10)**
   - 从 Book.newWords 取字
   - 按 recognize(50%) > meaning_select(30%) > pinyin_match(20%) 分配题型
   - 每字至少出现1次

3. **主题映射表**（v1.1教研提供）：

| 自然动物 | 兔、大、小、妈、白、飞、鸟、林 | 绘本03 |
| 校园 | 一、二、三、去、学、校、见、对 | 绘本04 |

| 公园 | 公、园、花、草、树、山、水、玩 | 绘本10 |

### 差距3：题目数量/题型分布不匹配

**教研确认**：同意，当前默认20题不适用于绘本测评。

**教研侧建议配置**：

```javascript
// 测评类型 → 题目数量 + 题型分布配置
const ASSESSMENT_CONFIG = {
  initial: {
    totalQuestions: 20,
    typeDistribution: {
      recognize: 8,      // 40%
      meaning_select: 7, // 35%
      pinyin_match: 5    // 25%
    }
  },
  review: {
    totalQuestions: 10,   // 绘本新字≤15时用10题
    typeDistribution: {
      recognize: 5,       // 50%
      meaning_select: 3,  // 30%
      pinyin_match: 2     // 20%
    }
  },
  level_test: {
    totalQuestions: 20,
    typeDistribution: {
      recognize: 8,
      meaning_select: 7,
      pinyin_match: 5
    }
  }
};
```

## 三、教研补充说明

1. **绘本01特殊处理**：绘本01仅有15个新字（其余绘本18字），题库按15题设计，每字恰好出现1次。
2. **干扰项图片素材**：看字选图（recognize）题型需要图片选项，这部分需要插画师配合产出。建议先开发听音选字和看图选字两种题型（不需要图片），recognize题型等素材就绪后补上。
3. **v1.2 规划**：questionGenerator.js 完成后，v1.2 将引入 SM-2 算法联动（根据遗忘曲线优先出薄弱字）。
