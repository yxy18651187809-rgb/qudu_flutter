# 字趣阅读 · 插画联动工作规范 v1

> 版本：v1.0 | 创建日期：2026-05-01 | 创建人：教研员
> 适用范围：100篇故事教案 × 插画师内容设计

---

## 一、联动流程总览

```
教研员                              插画师
  │                                  │
  ├─ Step 1: 故事文案定稿             │
  │  （故事正文+新字表+插画需求单）    │
  │                                  │
  ├─ Step 2: 交付需求单 ─────────────→│
  │                                  ├─ Step 3: 角色设定草图（1-2天）
  │←── 教研审核角色 ─────────────────┤
  │  （确认角色与故事一致性）          │
  │                                  ├─ Step 4: 分镜线稿（2-3天/本）
  │←── 教研审核分镜 ─────────────────┤
  │  （逐字核验新字+画面一致性）       │
  │                                  ├─ Step 5: 上色成稿（1-2天/本）
  │←── 教研终审 ────────────────────┤
  │  （色彩/风格/细节验收）            │
  │                                  │
  ├─ Step 6: 验收归档                │
  │  （命名规范+文件整理+QA）         │
```

### 各阶段交付物说明

| 步骤 | 负责人 | 交付物 | 审核要点 |
|:---:|:---:|:---|:---|
| Step 1 | 教研员 | 故事正文 + 新字表 + 插画需求单 | 文本准确性 |
| Step 2 | 教研员 | 需求单（正式版） | 完整性检查 |
| Step 3 | 插画师 | 角色设定草图（正面/侧面/表情） | 角色一致性 |
| Step 4 | 插画师 | 分镜线稿（每页一幅） | 新字呈现+画面连贯 |
| Step 5 | 插画师 | 上色成稿（完整高清图） | 色彩/风格验收 |
| Step 6 | 教研员+插画师 | 归档文件 + QA报告 | 最终验收 |

## 二、插画需求单模板

每篇故事教案附带以下需求单，插画师据此创作：

### 文件命名规范

```
{故事编号}_{类型}_{页码}.png
```

### 示例

| 文件名 | 说明 |
|:---|:---|
| `story_11_cover.png` | 封面 |
| `story_11_page01.png` | 第1页 |
| `story_11_page02.png` | 第2页 |
| `story_11_character.png` | 角色设定图 |
| `story_11_spritesheet.png` | 角色表情/动作素材表 |

### 需求单应包含

1. **故事基本信息**
   - 故事编号与标题
   - 目标年龄段
   - 级别（L1-L5）
   - 故事主题/类型

2. **角色设计需求**
   - 主要角色描述（含外貌、性格）
   - 配角描述
   - 趣趣（IP形象）出场要求
   - 角色动作/表情需求

3. **场景设计需求**
   - 故事发生的地点
   - 环境氛围描述
   - 色彩风格要求
   - 特殊道具/元素

4. **新字呈现要求**
   - 新字列表（18字/篇）
   - 新字在页面中的位置建议
   - 字体大小规范
   - 高亮方式

5. **分镜要求**
   - 总页数
   - 每页核心画面描述
   - 翻页节奏建议
   - 留白区域说明

## 三、质量标准

### 视觉风格统一规范

- **画风**：简约可爱，卡通风格，圆润线条
- **色彩**：明亮活泼，符合儿童审美，避免暗色系
- **字体**：新字使用 PingFang SC / Noto Sans SC，字号 ≥ 24pt
- **分辨率**：主图 ≥ 1440×1800px，导出 PNG
- **趣趣IP**：保持统一形象规范（见趣趣IP形象规范文档）

### 新字审核标准

- 每个新字必须清晰可辨，无遮挡
- 新字与背景有足够对比度
- 新字位置不得遮挡关键画面元素
- 不得出现错别字或Unicode编码错误

### 新字重复率标准（2026-05-02修订）

| 级别 | 允许重复率 | 说明 |
|:---:|:---:|:---|
| L1 启蒙级 | 0% | 严格不重复，建立基础字库 |
| L2-L5 起步/进阶/提高/流利 | ≤10% | 适度重复有助于记忆巩固 |

**重复字处理流程**：
1. 教研员在教案中标注"复习字"（用⚠️或"复习字"标识）
2. 插画师绘制时，复习字与新字同样高亮（但用不同底色）
3. 前端显示：新字用黄色底色（#FFFF00），复习字用蓝色底色（#E3F2FD）
4. 教学建议：复习字按"复习模式"出题（如：认读已学字）

## 四、交付时间要求

| 阶段 | 交付周期 | 备注 |
|:---|:---|:---|
| 角色设定草图 | 1-2天/角色组 | 可多个角色并行 |
| 分镜线稿 | 2-3天/本 | 需教研审核通过后方可上色 |
| 上色成稿 | 1-2天/本 | 绘本01-05优先 |
| 终审修订 | 0.5-1天/本 | 按审核意见修改 |

## 五、文件归档规范

### 最终交付文件结构

```
{故事编号}/
├── cover/
│   └── {story_XX}_cover.png          # 封面图
├── pages/
│   ├── {story_XX}_page01.png         # 第1页
│   ├── {story_XX}_page02.png         # 第2页
│   └── ...
├── characters/
│   └── {story_XX}_character.png      # 角色设定图
├── assets/
│   └── {story_XX}_spritesheet.png    # 角色素材表
└── review/
    ├── {story_XX}_review_char.png     # 角色审核版
    └── {story_XX}_review_final.png    # 终审版
```

## 六、沟通机制

- **需求变更**：教研员以书面形式通知插画师，注明变更原因
- **审核反馈**：每个审核步骤需在 24 小时内给出意见
- **紧急情况**：由运营/team-lead 协调优先级
