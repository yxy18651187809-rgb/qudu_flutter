## 六、工作规范提醒

### 6.1 联动流程（按规范执行）

```
教研员交付需求单 → 角色设定草图(1-2天) → 教研审核角色
→ 分镜线稿(2-3天) → 教研审核分镜 → 上色成稿(1-2天) → 教研终审 → 归档
```

### 6.2 文件命名规范

```
{故事编号}_{类型}_{页码}.png

示例：
story_03_cover.png      # 封面
story_03_page01.png     # 第1页
story_03_character.png   # 角色设定图
story_03_spritesheet.png # 角色素材表
```

### 6.3 分镜线稿审核要点

- [ ] 每个新字必须清晰呈现
- [ ] 新字位置不得遮挡画面关键元素
- [ ] 画面连贯性检查
- [ ] 角色一致性检查
- [ ] 色彩/风格符合视觉规范
