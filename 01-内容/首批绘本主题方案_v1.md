## 二、创作原则

### 2.1 语言规范（L1级）

- **句式**：简单主谓句/主谓宾句为主
- **重复**：核心句式重复3-5次，强化记忆
- **韵律**：适当使用叠词、拟声词
- **人称**：第二人称"你"或第三人称"它"
- **标点**：句号、感叹号为主，避免复杂标点

### 2.2 插画配合要求

- 图画占比：≥60%（文字占比≤40%）
- 画面元素：清晰、具象、色彩鲜明
- 新字提示：重要生字对应的物体在插画中突出显示
- 页面布局：文字在画面下方或留白区域，不遮挡关键图像

### 2.3 教育目标分层

| 层级 | 说明 | 示例 |
|:---:|:---|:---|
| 识字目标 | 必须掌握的生字 | 人、口、手 |
| 理解目标 | 通过故事理解的概念 | 身体各部位名称 |
| 情感目标 | 传递的价值观 | 认识自己、爱护身体 |

## 三、各绘本详情

### 📖 绘本1：《我的身体》

**识字目标（20字）**：
```
人、口、手、足、头、脸、眼、耳、鼻、心
十、只、个、会、能、爱、我、你、他、她
```

**故事大纲**：
> 小主人公"我"起床后，对着镜子认识自己的身体部件。
> 从头到脚，每个部位都有自己的名字和用处。
> 最后发现，每个人都是独一无二的"我"。

**教育目标**：
- ✅ 认识身体主要部位
- ✅ 建立自我认同感
- ✅ 理解"我"的独特性

**句式模板**：
```
这是我的（头）。
我的（眼睛）会看。
我有（两只）手。
```

**创作状态**：✅ 准备开始

### 📖 绘本2：《早上好》

**识字目标（20字）**：
```
日、早、上、天、明、亮、起、洗、刷、吃
太、阳、出、来、去、爸、妈、爷、奶、好
```

**故事大纲**：
> 小女孩小明的早晨：从太阳升起，到起床洗漱，再到和家人吃早餐。
> 一天天的重复中，时间在流动，早晨充满希望。

**教育目标**：
- ✅ 认识早晨的代表性事物
- ✅ 理解时间的概念
- ✅ 养成良好作息习惯

**句式模板**：
```
（太阳）出来了。
早上好！
我（起床）了。
```

**创作状态**：📝 待创作

### 📖 绘本3：《小兔子找妈妈》

**识字目标（20字）**：
```
大、小、山、石、林、草、找、妈、爱、回、跑
走、跳、见、说、哭、笑、怕、不、要、的
```

**故事大纲**：
> 小兔子在森林里玩，和妈妈走散了。
> 在寻找妈妈的路上，遇到了石头、山、大树...
> 最后通过呼叫妈妈的名字，找到了妈妈。
> 妈妈的爱永远不会走丢。

**教育目标**：
- ✅ 认识大小、山石、树林等自然事物
- ✅ 理解方位概念
- ✅ 感受亲情的温暖与安全感

**句式模板**：
```
小兔子（在找）妈妈。
这是（一座）山。
妈妈，我（要回家）。
```

**创作状态**：📝 待创作

### 📖 绘本4：《一二三，上学去》

**识字目标（20字）**：
```
一、二、三、四、五、上、学、校、友、师
见、你、好、请、谢、对、不、客、气
```

**故事大纲**：
> 小男孩豆豆第一天上学。手里数着1、2、3...背着书包出门。
> 到了学校，见到老师问好，见到同学打招呼。
> 原来上学这么有趣！

**教育目标**：
- ✅ 认识数字1-5
- ✅ 了解学校生活
- ✅ 学会礼貌问候

**句式模板**：
```
（1、2、3），我（上）学去！
（同学）你好！
谢谢（老师）！
```

**创作状态**：📝 待创作

### 📖 绘本5：《红红的太阳》

**识字目标（20字）**：
```
红、黄、蓝、绿、白、黑、光、照、暖、亮
天、云、雨、风、雪、星、月
```

**故事大纲**：
> 小画家小美想要画一幅彩虹图。
> 她去找红色的太阳、黄色的香蕉、蓝色的天空...
> 最后把所有颜色合在一起，画出了最美的彩虹。

**教育目标**：
- ✅ 认识基本颜色词
- ✅ 观察自然中的色彩
- ✅ 培养创造力和观察力

**句式模板**：
```
（太阳）是（红）色的。
天上有（蓝）色的（云）。
我看见（彩）虹了！
```
