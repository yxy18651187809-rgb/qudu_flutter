## 三、故事正文（分页脚本）
### Page 1-2
【画面描述】教室里，老师问同学们："你的梦想是什么？"孩子们争先恐后举手。
【文字】今天的班会课上，老师问大家："小朋友们，你们长大了想做什么？"教室里一下子热闹起来，同学们争先恐后地举手。
【新字】梦、想、师、教
### Page 3-4
【画面描述】小红站起来说想当医生，画面展示医生在医院工作的场景。
【文字】小红第一个站起来说："我想当一名医生！医生可以治好病人的病，让人恢复健康。"老师点点头："医生很伟大，要有责任心才行。"
【新字】医、护、病、治、责
### Page 5-6
【画面描述】小刚说想当科学家，画面展示科学家在实验室做实验。
【文字】小刚站起来说："我想当科学家！我要研究为什么天会下雨，为什么星星会发光。"老师说："科学家要善于观察和思考，不怕失败。"
【新字】科、研、究、怕、失
### Page 7-8
【画面描述】小明说想当飞行员，画面展示飞机在蓝天飞行。
【文字】小明站起来大声说："我想当飞行员！我要飞到天空上去，看看云朵上面是什么样子！"同学们都"哇"了一声。
【新字】飞、航、天、员
### Page 9-10
【画面描述】其他同学也纷纷说出自己的梦想：画家、歌手、老师等。
【文字】小芳说："我想当画家，画出世界上最美的画。"小强说："我想当歌手，唱出动听的歌曲。"小丽说："我想当老师，教小朋友们读书认字。"
【新字】画、家、唱、歌、演
### Page 11-12
【画面描述】老师让大家回家问爸爸妈妈，了解不同职业的工作内容。
【文字】老师笑着说："每种职业都很了不起。你们回家问问爸爸妈妈，他们的工作是什么样的，好不好？"同学们齐声说："好！"
【新字】每、种、了、起、齐
### Page 13-14
【画面描述】小明回家问爸爸，爸爸是建筑工人，正在盖房子。
【文字】小明回到家，问爸爸："爸爸，你的梦想是什么？"爸爸说："我的梦想是当一名建筑师，建造又高又安全的房子。虽然我现在还在学习，但我会努力的。"
【新字】建、筑、造、安、全
### Page 15-16
【画面描述】小明又问妈妈，妈妈是护士，正在照顾病人。
【文字】妈妈是一名护士。她说："我的梦想很简单，就是照顾好每一个病人。虽然有时候很辛苦，但看到病人好了，我就很开心。"
【新字】简、单、辛、苦、虽
### Page 17
【画面描述】小明躺在床上想梦想的事，窗外星空灿烂。
【文字】那天晚上，小明躺在床上想：每个大人都有自己的梦想。不管是什么梦想，都需要努力才能实现。从明天开始，我要好好学习，追着自己的梦想往前跑！
【新字】追、求、任、务、努
### Page 18
【画面描述】小明站在山顶上，对着朝阳张开双臂，画面充满希望。
【文字】不管梦想是什么，最重要的是要有勇气去追求。只要不怕困难，努力去做，梦想就一定会实现！小明想好了，他的梦想——先当一个努力学习的好孩子！
【新字】勇、气、难、功

【教育目标】会认：梦想、医生、护士、治疗、科学家、研究、飞行员、责任、努力、追求 | 会写：梦、想、医、病、治、科、飞、歌、追、功
【品德目标】认识不同职业的价值，理解每个梦想都需要努力和责任，学会尊重他人的选择
【练习】1.同学们的梦想分别是什么？2.小明的爸爸和妈妈做什么工作？3.实现梦想需要什么？4.你的梦想是什么？为什么？5.你觉得什么品质对实现梦想最重要？
