# 字趣阅读 · 插画需求单颗粒度对齐清单

> **目的**：确保教研员与插画师对需求单的理解一致，减少返工
> **使用方式**：请插画师逐条确认，有疑问立即提出

---

## 一、需求单阅读顺序（重要）

插画师收到需求单后，请按以下顺序阅读：

```
1. 基本信息（级别/L1启蒙级/目标年龄段）
   ↓ 确认画风基调
2. 角色设计需求（主要角色/配角/趣趣IP）
   ↓ 先画角色设定草图，等教研审核
3. 场景设计需求（场景表/特殊道具）
   ↓ 理解每页环境氛围和色彩
4. 新字图片需求（新字列表/位置/高亮方式）
   ↓ 关键！新字必须清晰可辨
5. 分镜需求（每页分镜描述/翻页节奏）
   ↓ 理解故事节奏，开始画分镜线稿
6. 文件命名预览
   ↓ 按规范命名，方便归档
```

## 二、颗粒度标准（逐条确认）

### 2.1 角色设定草图

| 检查项 | 标准 | 常见偏差 |
|:---|:---|:---|
| 角色比例 | Q版，头身比 1:1 或 1:2 | 身体太长，不像儿童画风 |
| 趣趣IP | 严格按《趣趣IP形象规范》 | 自行发挥，形象不一致 |
| 表情数量 | 至少3种（开心/疑惑/惊讶） | 只有一种表情，复用 |
| 服装细节 | 与故事描述一致 | 遗漏道具（如背包、帽子） |
| 交付格式 | PNG，透明背景，≥512×512px | 合并在白底上，难以复用 |

✅ **验收标准**：教研员在24小时内反馈，插画师按意见修改后进入分镜阶段。

---

### 2.2 分镜线稿

| 检查项 | 标准 | 常见偏差 |
|:---|:---|:---|
| 新字呈现 | 每个新字在分页描述中明确对应画面元素 | 新字未在画面中体现 |
| 文字区域 | 下方1/3留白，不压画面主体 | 文字区域太小，或压住主角 |
| 翻页节奏 | 按需求单标注（慢2秒/中1.5秒/快1秒） | 节奏单一，无情绪变化 |
| 画面连贯性 | 相邻两页场景/角色位置有逻辑关联 | 场景跳变，儿童困惑 |
| 趣趣IP位置 | 作为引导者，不抢主角戏份 | 趣趣太大，喧宾夺主 |

✅ **验收标准**：逐页审核，每页标注「通过/修改建议」，插画师修订后重新提交。

---

### 2.3 上色成稿

| 检查项 | 标准 | 常见偏差 |
|:---|:---|:---|
| 色彩饱和度 | L1启蒙级：低饱和度暖色系（莫兰迪色系） | 颜色过鲜艳，刺激儿童眼睛 |
| 新字对比度 | 新字与背景对比度 ≥ 4.5:1（WCAG AA） | 新字融入背景，看不清 |
| 高亮方式 | 按需求单执行（底色高亮/边框/下划线） | 自行更换高亮方式 |
| 分辨率 | ≥ 1440×1800px，导出PNG | 分辨率不足，前端放大后模糊 |
| 文件大小 | 单页 ≤ 500KB（压缩后） | 文件过大，App加载慢 |

✅ **验收标准**：色彩/风格/细节全部通过后，文件归档。

## 三、新字呈现颗粒度（核心！）

这是最容易出现偏差的地方，请插画师特别注意：

### 3.1 新字在画面中的呈现方式

| 方式 | 适用场景 | 示例 |
|:---|:---|:---|
| **直接融入画面** | 具象字（山、水、鱼、鸟） | 画一座山，旁边标「山」字 |
| **角色动作配合** | 动作字（跑、跳、吃、笑） | 小兔子在跑，旁边标「跑」字 |
| **场景元素标注** | 场景字（天、地、家、门） | 画一扇门，旁边标「门」字 |
| **颜色区分** | 抽象字（的、了、不、是） | 用颜色高亮（如淡黄底色） |

### 3.2 新字标注规范

```
【正确示例】
- 新字「山」：画一座山，山的轮廓用深色，字「山」放在画面右上角
  - 字体：PingFang SC / Noto Sans SC，≥24pt
  - 高亮：淡蓝色底色（#E3F2FD），圆角3px
  - 与背景对比度：≥ 4.5:1

【错误示例】
- 新字「山」：只画了山，但画面中没有「山」这个字
  → 儿童不知道这个字怎么写
- 新字「的」：字体太小（12pt），儿童看不清
  → 必须 ≥ 24pt
- 新字「天」：字是白色，背景是白云
  → 对比度不足，看不清
```

## 四、文件交付颗粒度

### 4.1 文件命名规范（严格执行）

```
{故事编号}_{类型}_{页码}.png

正确示例：
- story_11_cover.png     ✅ 封面
- story_11_page01.png    ✅ 第1页
- story_11_page02.png    ✅ 第2页
- story_11_character.png ✅ 角色设定图
- story_11_spritesheet.png ✅ 角色表情/动作素材表

错误示例：
- 数一数封面.png          ❌ 含中文，跨平台乱码
- story11page1.png        ❌ 缺少下划线和类型标识
- 11_封面_final_v2.png    ❌ 命名格式不统一
```

### 4.2 交付包结构

```
交付包文件夹命名：L1-11_数一数_插画交付_v1
├── cover/
│   └── story_11_cover.png
├── pages/
│   ├── story_11_page01.png
│   ├── story_11_page02.png
│   └── ...
├── characters/
│   └── story_11_character.png
├── assets/
│   └── story_11_spritesheet.png
└── README.md  ← 交付说明（页数/分辨率/文件大小清单）
```

## 五、审核反馈颗粒度

### 5.1 教研审核反馈格式（插画师必读）

教研审核后，会返回以下格式的意见：

```markdown
## 审核结果：❌ 需修改 / ✅ 通过

### 修改意见（逐页）
| 页码 | 状态 | 修改意见 | 优先级 |
|------|------|----------|--------|
| P01 | ❌ 需修改 | 新字「一」位置被角色遮挡，调整到左上角 | P0 |
| P02 | ✅ 通过 | — | — |
| P03 | ⚠️ 建议优化 | 色彩可以再暖一点，当前偏冷 | P1 |

### P0问题（必须修改，否则不进入下一阶段）
- 新字遮挡/看不清
- 新字缺失（需求单列了但画面没有）
- 角色形象与设定不符
- 文件命名错误

### P1问题（建议优化，可不修改直接进入下一阶段）
- 色彩微调
- 构图优化
- 细节补充
```

### 5.2 插画师修改响应规范

| 响应时间 | 场景 |
|:---|:---|
| 4小时内 | P0问题（必须修改） |
| 24小时内 | P1问题（建议优化） |
| 立即通知 | 修改完成后，发回教研复审 |

## 六、常见问题FAQ（插画师必读）

| 问题 | 回答 |
|:---|:---|
| 需求单里的「超纲字」怎么处理？ | 超纲字不强制识字，用**图片辅助**方式呈现（如「饼」字配月饼图片） |
| 趣趣IP在每个故事里都出现吗？ | 是的，作为**引导者/观察者**，不抢主角戏份 |
| 新字可以放在画面中间吗？ | 可以，但必须保证**不遮挡关键画面元素** |
| 如果我觉得某个分镜描述不合理，能改吗？ | 可以，但必须**先和教研员确认**，不能自行修改 |
| 文件交付后还能修改吗？ | 可以，但会进入**修订流程**，影响交付时间 |
| L1和L2的画风有区别吗？ | 有！L1更简约、色彩更柔和；L2稍复杂，可加入更多细节 |
