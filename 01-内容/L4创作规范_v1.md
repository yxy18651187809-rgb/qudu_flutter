## 一、L4级别定位

| 项目 | 标准 |
|:---|:---|
| **级别名称** | L4 提升级 |
| **目标年龄** | 8-10岁 |
| **识字量** | 1500字（累计，在L3的1000字基础上新增500字） |
| **故事篇数** | 20篇（第65-84篇） |
| **每篇字数** | 1000-1500字 |
| **每篇新字** | 30-40字（核心字+适量扩展字） |
| **故事页数** | 20-24页 |
| **主题分布** | 六大主题均衡（传统/科学/社交/成长/自然/认知） |

### 1.1 与L3的差异

| 维度 | L3 发展级 | L4 提升级 |
|:---|:---|:---|
| 年龄段 | 7-8岁 | 8-10岁 |
| 累计识字量 | 1000字 | 1500字（+500） |
| 每篇字数 | 500-800字 | 1000-1500字 |
| 每篇新字 | 25-35字 | 30-40字 |
| 页数 | 16-20页 | 20-24页 |
| 句式复杂度 | 复合句≥40% | 复合句≥60%，含因果/转折/递进 |
| 主题深度 | 基础认知 | 批判性思维萌芽 |

## 二、L4创作标准

### 2.1 故事结构（6部分）

1. **故事信息表** - 编号、名称、主题、字数、页数、新字列表
2. **新字表** - 汉字、拼音、笔画、部首、组词、是否核心字、备注（L1-L3复习字标注）
3. **故事正文（分页脚本）** - 每页：画面描述、文字、拼音、新字标注
4. **教育目标** - 识字、认知、情感、能力4维度
5. **配套练习（5题）** - 图文配对、判断正误、选择题、排序题、开放题
6. **插画需求单** - 角色、场景、配色、新字图片需求、封面需求

### 2.2 分页脚本规范

| 项目 | L4标准 |
|:---|:---|
| **每页文字** | 50-70字（比L3的30-50字多） |
| **拼音标注** | 仅新字标注拼音（非全文拼音，与L3不同） |
| **新字标注** | 每页2-3个新字（含复习字） |
| **画面描述** | 100-150字（比L3的80-120字更详细） |
| **句式复杂度** | 复合句≥60%，关联词丰富（因为...所以...、虽然...但是...、不仅...还...） |
| **段落结构** | 支持多段落叙事（每页可分2-3段） |

### 2.3 新字选择标准

1. **核心字优先** - 从L4核心字表（1500字范围内，1000字基础上新增500字）选择
2. **L1-L3复习字** - 每篇5-8个复习字（标注来源级别）
3. **超纲字控制** - 每篇≤8个超纲字（需图片辅助或脚注）
4. **新字重复率** - 同级别内≤5%重复，跨级别复习字有意识安排
5. **新字分布** - 前12页引入25-30字，后8-12页巩固+少量新字

### 2.4 教育目标深度（相比L3提升）

| 维度 | L3标准 | L4标准 |
|:---|:---|:---|
| **识字** | 会认25-35字，会写10字 | 会认30-40字，会写其中15字 |
| **认知** | 因果关系理解 | 多重因果关系、分类比较、简单推理 |
| **情感** | 复杂情感理解（愧疚、自豪） | 情感管理、同理心、价值观判断 |
| **能力** | 逻辑表达（先...然后...最后...） | 观点表达（我认为...因为...）、简要论述 |

### 2.5 主题深度标准

| 主题 | L3深度 | L4深度 |
|:---|:---|:---|
| 🌿 自然与动物 | 基础观察、简单分类 | 生态系统、物种关联、环保意识 |
| 👨‍👩‍👧 生活与社交 | 日常场景、朋友关系 | 社区生活、多元文化、社会规则 |
| 🔢 认知与启蒙 | 基础概念 | 逻辑推理、批判性思维萌芽 |
| 🏮 传统文化 | 故事了解 | 文化内涵理解、现代意义 |
| 🔬 科学探索 | 现象描述 | 原理解释、实验思维 |
| 💪 成长与品格 | 品质认知 | 品格内化、人生智慧 |

## 三、L4字库范围

### 3.1 累计识字量目标

| 级别 | 累计识字量 | 新增字数 |
|:---:|:---:|:---:|
| L1 | 301字 | 301字 |
| L2 | 386字（301+85） | 85字 |
| L3 | 584字（386+~200） | ~198字 |
| **L4** | **~1500字** | **~916字** |
| L5 | ~2500字 | ~1000字 |

### 3.2 L4新字选字参考

L4新字应在以下范围内优先选择：

1. **小学3-4年级常用字** — 教育部义务教育语文课程标准
2. **L4故事主题相关字** — 科学、历史、文化等领域高频字
3. **L1-L3低频但重要的字** — 在前三级中出现但掌握度低的字

### 3.3 字库JSON格式

待创建 `L4完整字_后端导入.json`，格式与L2一致：
```json
{
  "level": "L4",
  "total": 1500,
  "characters": [
    {
      "character": "融",
      "pinyin": "róng",
      "strokes": 16,
      "radical": "虫",
      "structure": "左右",
      "wordExamples": ["融入", "融合"],
      "frequency": "core"
    }
  ]
}
```

## 六、L4创作时间估算

| 任务 | 时间估算 | 说明 |
|:---|:---:|:---|
| **单篇规范化（从草稿到正式版）** | 10-15分钟 | 编号修正+格式检查+补充缺失字段 |
| **单篇新字去重验证** | 3-5分钟 | 跨篇比对 |
| **20篇规范化（全级）** | 4-5小时 | 含拆分+重编号+验证 |
| **L4字库JSON生成** | 1-2小时 | 汇总20篇新字+去重+格式化 |
| **L4缺失内容补充（如有）** | 30分钟/篇 | 仅对内容不完整的草稿 |
