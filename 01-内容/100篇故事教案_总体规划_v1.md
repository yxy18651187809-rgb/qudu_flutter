## 四、故事教案模板

每篇故事教案包含以下结构：

```
一、基本信息
   - 编号、级别、故事名、主题、页数、总字数
   - 目标年龄、新字数量、新字列表
   - 复习字列表、教育目标

二、新字表
   - 每字的：汉字、拼音、笔画、部首、组词、造句

三、故事正文（分页脚本）
   - 每页：页码、画面描述、文字、拼音、新字标注
   - 超纲字用图片/图标辅助说明

四、教育目标
   - 识字目标、认知目标、情感目标、能力目标

五、配套练习（5题）
   - 图文配对、判断正误、选择题、排序题、开放题

六、插画需求单（联动插画师）
   - 角色设定、场景描述、风格要求、配色方案
   - 分镜需求（每页画面描述+重点标注）
   - 封面需求
```

  │                            │
  │←─ 教研审核角色设定 ─────────┤
  │                            │
  │                            ├─ 4. 分镜线稿
  │                            │
  │←─ 教研审核分镜 ─────────────┤
  │   （新字覆盖+画面一致性）    │
  │                            │
  │                            ├─ 5. 上色成稿
  │                            │
  │←─ 教研终审 ────────────────┤
  │                            │
  ├─ 6. 验收归档               │
  │                            │

## 七、质量标准

| 维度 | 标准 |
|------|------|
| 识字量 | 每篇新字不超标（L1≤18字，L2≤25字，L3≤35字，L4≤40字，L5≤60字） |
| 字库覆盖 | 新字必须在对应级别字库范围内 |
| 去重率 | 同级别内新字尽量不重复，跨级别复习字有意识安排 |
| 超纲率 | 超纲字≤10%，超纲字必须用图片/图标辅助 |
| 趣味性 | 包含悬念、反转、互动等元素 |
| 教育性 | 每篇至少涵盖2个教育维度 |
| 文化性 | 传统文化主题占比≥15% |
