# 字趣阅读 · 复习字显示规范 v1

> 创建日期：2026-05-02 | 创建人：教研员
> 适用范围：前端开发团队
> 目的：明确新字与复习字在APP中的视觉区分

---

## 一、背景说明

L2-L5级别允许≤10%的新字重复率（L1严格0重复）。重复字标注为"复习字"，在教学中按复习模式处理。

---

## 二、显示规范

### 2.1 颜色区分

| 类型 | 底色 | 字体色 | 边框 | 示例 |
|:---|:---|:---|:---|:---|
| **新字** | 黄色 `#FFFF00` | 黑色 `#000000` | 无 | 雨 |
| **复习字** | 蓝色 `#E3F2FD` | 深蓝 `#1565C0` | 蓝色 `#1976D2` 1px实线 | 雨（复习） |

### 2.2 字体规范

- **字号**：与新字一致（≥24pt）
- **字体**：PingFang SC / Noto Sans SC（与新字统一）
- **位置**：与新字相同（页面中标注位置）

### 2.3 交互差异

| 功能 | 新字 | 复习字 |
|:---|:---|:---|
| **点击发音** | ✅ 支持 | ✅ 支持（语速稍快，模拟复习） |
| **认读测试** | ✅ 重点考察 | ✅ 简单提示后考察 |
| **星星奖励** | ✅ 认对给星 | ✅ 认对也给星（但星数×0.5） |
| **复习标识** | 无 | 右上角小字"复习" |

---

## 三、数据字段规范

### 3.1 后端API返回格式

```json
{
  "character": "雨",
  "pinyin": "yǔ",
  "isNew": true,        // true=新字, false=复习字
  "isReview": false,    // true=复习字
  "reviewFrom": null    // 复习字时，填首次出现的故事编号（如"L2-021"）
}
```

### 3.2 前端模型适配

**文件**：`lib/models/word_model.dart`

```dart
class WordModel {
  final String character;
  final String pinyin;
  final bool isNew;
  final bool isReview;
  final String? reviewFrom; // 首次出现位置
  
  // 显示样式
  Color get backgroundColor => isReview ? Color(0xFFE3F2FD) : Color(0xFFFFFF00);
  Color get textColor => isReview ? Color(0xFF1565C0) : Color(0xFF000000);
  bool get showReviewBadge => isReview;
}
```

## 五、测试用例

### 5.1 新字显示测试

1. 打开L2-035《雨天和晴天》P01
2. 检查"雨"字是否显示为**黄色底色**
3. 点击"雨"字，是否播放拼音发音
4. 认读测试时，"雨"是否按新字标准考察

### 5.2 复习字显示测试

1. 打开L2-035《雨天和晴天》P01
2. 检查"雨"字是否显示为**蓝色底色**（如果是复习字）
3. 右上角是否有"复习"小标识
4. 点击发音，语速是否稍快
5. 认读测试时，是否简单提示后考察

### 5.3 星星奖励测试

1. 完成L2-035测评
2. 复习字认对，是否给星但星数×0.5（如：原2星→实得1星）
3. 统计页面是否分别显示"新字X/18"和"复习字X/4"
