## 题目列表

### 一、看字选图（recognize）× 5题

> **题型说明**：显示汉字，从4张图片中选择正确的一张。
> **干扰项策略**：同绘本新字 > 同主题字 > 随机L1字

#### Q01 | 人 | ⭐

```
题目：显示大字卡片"人"
趣趣："这是哪个字呀？"
选项：
  A. 👤 小朋友（正确）     ← 一个人站着的图片
  B. 👋 手                 ← 一只手的图片（同绘本新字干扰）
  C. 👂 耳                 ← 一只耳朵的图片（同绘本新字干扰）
  D. 👁 眼                 ← 一只眼睛的图片（同主题干扰）
正确答案：A
干扰策略：同绘本新字(手、耳) + 同主题(眼)
```

#### Q02 | 口 | ⭐

```
题目：显示大字卡片"口"
趣趣："找到这个字对应的图片！"
选项：
  A. ✋ 手                 ← 一只手的图片（同绘本干扰）
  B. 👄 嘴巴（正确）       ← 张开的嘴巴特写
  C. 👂 耳朵               ← 耳朵图片（同绘本干扰）
  D. ☀️ 太阳               ← 太阳图片（随机干扰）
正确答案：B
干扰策略：同绘本新字(手、耳) + 随机(太阳)
```

#### Q03 | 手 | ⭐

```
题目：显示大字卡片"手"
趣趣："这张图片是哪个字？"
选项：
  A. 👤 人                 ← 一个人（同绘本干扰）
  B. 🦶 脚/足              ← 一只脚的图片（同主题干扰）
  C. ✋ 手（正确）          ← 一只手的图片
  D. 🌳 树                 ← 树的图片（随机干扰）
正确答案：C
干扰策略：同绘本新字(人) + 同主题(足) + 随机(树)

### 二、看图选字（meaning_select）× 5题

> **题型说明**：显示图片，从4个汉字中选择正确的一个。
> **干扰项策略**：形近字 > 同主题字 > 同绘本字 > 随机L1字

#### Q06 | 大 | ⭐

```
题目：显示大西瓜的图片 🍉（很大很大的西瓜）
趣趣："这个西瓜怎么样？"
选项：
  A. 大（正确）            ← 正确
  B. 太                   ← 形近字干扰（大+点=太）
  C. 小                   ← 反义词干扰（同主题）
  D. 天                   ← 随机L1字干扰
正确答案：A
干扰策略：形近(太) + 反义(小) + 随机(天)
```

#### Q07 | 小 | ⭐

```
题目：显示小蚂蚁的图片 🐜
趣趣："这只蚂蚁是什么样子的？"
选项：
  A. 少                   ← 随机干扰
  B. 大                   ← 反义词干扰
  C. 小（正确）            ← 正确
  D. 上                   ← 随机L1字干扰
正确答案：C
干扰策略：反义(大) + 随机(少、上)
```

#### Q08 | 足 | ⭐⭐

```
题目：显示小脚丫的图片 🦶
趣趣："我们走路用的是哪个字？"
选项：
  A. 手                   ← 同绘本/同主题干扰（身体部位）
  B. 足（正确）            ← 正确
  C. 口                   ← 同绘本干扰
  D. 走                   ← 随机L1字干扰（动作相关）
正确答案：B
干扰策略：同绘本同主题(手、口) + 相关动作(走)
注：足字笔画略多，难度⭐⭐
```

#### Q09 | 耳 | ⭐⭐

```
题目：显示大象耳朵的图片 🐘（大耳朵特写）
趣趣："大象用它来听声音，这是什么？"
选项：
  A. 目                   ← 形近/相关干扰（眼睛的另一种说法）
  B. 口                   ← 同绘本/同主题干扰（面部器官）
  C. 耳（正确）            ← 正确
  D. 头                   ← 同绘本/同主题干扰（身体部位）
正确答案：C
干扰策略：相关(目) + 同绘本同主题(口、头)
注：耳字6画，难度⭐⭐
```

#### Q10 | 我 | ⭐⭐

```
题目：显示小朋友指着自己的图片（小明自拍姿势）
趣趣："小朋友说'这是我！'，这个字是什么？"
选项：
  A. 你                   ← 反义/同主题干扰（代词）
  B. 找                   ← 形近字干扰（我+扌=找，左边相似）
  C. 人                   ← 同绘本干扰（身体/人称）
  D. 大                   ← 随机干扰
正确答案：B（这里应是"我"为正确答案）
修正：
  A. 你                   ← 反义/同主题干扰（代词）
  B. 大                   ← 随机干扰
  C. 我（正确）            ← 正确
  D. 人                   ← 同绘本干扰（人称）
正确答案：C
干扰策略：代词(你) + 同绘本(人) + 随机(大)
```

### 三、听音选字（pinyin_match）× 5题

> **题型说明**：播放拼音语音，从4个汉字中选择正确的一个。
> **干扰项策略**：音近字 > 形近字 > 同绘本字 > 随机L1字

#### Q11 | 你 | ⭐

```
题目：播放语音 "nǐ"（自动播放1次，可点击重播）
趣趣："找到 nǐ！"
选项：
  A. 你（正确）            ← 正确
  B. 泥                   ← 音近字干扰（同音ní，声调不同）
  C. 尼                   ← 音近字干扰（同音ní，声调不同）
  D. 人                   ← 同绘本干扰（同为2画）
正确答案：A
干扰策略：音近(泥、尼) + 同绘本(人)
```

#### Q12 | 是 | ⭐

```
题目：播放语音 "shì"
趣趣："听一听，是哪个字？"
选项：
  A. 十                   ← 音近字干扰（同音shí，声调不同）
  B. 时                   ← 音近字干扰（同音shí，声调不同）
  C. 是（正确）            ← 正确
  D. 对                   ← 同绘本干扰（近义字）
正确答案：C
干扰策略：音近(十、时) + 近义(对)
```

#### Q13 | 的 | ⭐

```
题目：播放语音 "de"（轻声）
趣趣："de~ 是哪个字？"
选项：
  A. 得                   ← 音近字干扰（同音dé，声调不同）
  B. 地                   ← 音近字干扰（同音dì，声调不同）
  C. 的（正确）            ← 正确
  D. 他                   ← 同主题干扰（代词/语法字）
正确答案：C
干扰策略：音近(得、地) + 同主题(他)
```

#### Q14 | 了 | ⭐

```
题目：播放语音 "le"（轻声）
