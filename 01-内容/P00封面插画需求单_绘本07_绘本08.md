## 一、绘本07《家的小动物》P00封面

### 1.1 封面文案

| 项目 | 内容 |
|:---|:---|
| **绘本名称** | 家的小动物 |
| **封面副标题** | （无） |
| **系列标识** | 字趣阅读 · L1启蒙级 |
| **封面标语** | 跑一跑，飞一飞，小动物真有趣！ |

### 1.2 新字选取（封面展示）

从18字中选取 **6个核心视觉字** 用于封面新字标注气泡：

| 汉字 | 拼音 | 选取理由 |
|:---:|:---:|:---|
| 猫 | māo | 主角动物，画面核心 |
| 狗 | gǒu | 主角动物，画面核心 |
| 鱼 | yú | 视觉差异化（水中动物） |
| 鸟 | niǎo | 视觉差异化（空中动物） |
| 跑 | pǎo | 动态动作字，画面张力 |
| 飞 | fēi | 动态动作字，画面张力 |

> **选取原则**：优先选画面表现力强的动物字+动作字，避免「虫」「猪」「鸭」等视觉辨识度较低的，也避免「游」「爬」「快」「慢」「笑」等抽象动作/形容词在封面堆砌。

### 1.3 封面插画需求

- **画面描述**：温馨的农场小院场景。中央是一只橘色小猫和一只棕色小狗，小狗在前面跑，小猫在后面追。画面左侧上方有一只小鸟在树枝上飞，右侧下方有金鱼在清澈的小水塘里游。背景是蓝天白云、绿色草地、远处有小木栅栏和一棵大树。整体氛围温暖活泼，色彩明快。
- **文字内容**：家的小动物
- **拼音**：jiā de xiǎo dòng wù（小字标注在标题下方，字号较小，不抢视觉）
- **新字标注**：猫、狗、鱼、鸟、跑、飞（半透明暖黄色气泡标注，分布在对应动物/动作旁边）
- **插画重点**：
  - 猫狗追逐的动态感（跑的意象）
  - 小鸟展翅飞翔（飞的意象）
  - 金鱼在水中游动的轻盈感
  - 农场小院的整体温馨氛围
- **画面占比**：动物角色45% / 场景背景40% / 文字区域15%
- **配色建议**：主色暖橙+草绿（自然生机），辅助天蓝+奶白

### 1.4 角色形象要求

| 角色 | 形象要求 | 风格 |
|:---|:---|:---|
| 猫 | 橘色短毛猫，大眼睛，尾巴翘起，表情活泼 | Q版可爱，圆润线条 |
| 狗 | 棕色小狗（类似柴犬），耳朵竖起，嘴巴张开笑着 | Q版可爱，圆润线条 |
| 鸟 | 黄色小鸟，翅膀展开，嘴里可能衔着小树枝 | 小巧灵动 |
| 鱼 | 红金色鲤鱼，鱼鳞清晰可见，尾巴优美摆动 | 简洁圆润 |

## 二、绘本08《四季歌》P00封面

### 2.1 封面文案

| 项目 | 内容 |
|:---|:---|
| **绘本名称** | 四季歌 |
| **封面副标题** | （无） |
| **系列标识** | 字趣阅读 · L1启蒙级 |
| **封面标语** | 春风秋叶冬雪飘，一年四季真美好！ |

### 2.2 新字选取（封面展示）

从18字中选取 **6个核心视觉字** 用于封面新字标注气泡：

| 汉字 | 拼音 | 选取理由 |
|:---:|:---:|:---|
| 春 | chūn | 季节核心字，视觉辨识度最高 |
| 秋 | qiū | 季节核心字，代表性强 |
| 冬 | dōng | 季节核心字，视觉辨识度高 |
| 树 | shù | 场景核心元素，四季变化的载体 |
| 草 | cǎo | 自然元素，与树搭配构成场景 |
| 花 | （非新字，作为装饰） | — |

> **备选方案**：若6字不够，可补充「冰」「河」增强冬季/自然画面感。但封面字不宜过多，6个为上限，保持画面清爽。

### 2.3 封面插画需求

- **画面描述**：一棵大树在画面中央，树冠被分为四个区域，分别呈现四季景象——左上角春（粉色花朵+绿叶）、右上角秋（金黄落叶+橙色果实）、左下角夏（浓密绿叶+鸟窝，不标「夏」字因为是复习字）、右下角冬（光秃枝干+雪花+冰挂）。树根下是绿色草地和一条小河（河面右下角有一小片薄冰）。大树旁站着一个小男孩，抬头望着大树，表情好奇欣喜。背景是渐变的天空色（上方蓝、远处橙黄）。
- **文字内容**：四季歌
- **拼音**：sì jì gē（小字标注在标题下方）
- **新字标注**：春、秋、冬、树、草、冰（半透明暖黄色气泡标注，分布在对应元素旁边）
- **插画重点**：
  - 一棵树呈现四季的变化——这是封面最核心的创意点
  - 春（花）与秋（果）的色彩对比
  - 冬天的雪花和冰挂细节
  - 小男孩仰望大树的好奇表情
  - 小河+薄冰的自然元素
- **画面占比**：大树+四季元素40% / 场景背景35% / 人物10% / 文字区域15%
- **配色建议**：四季渐变色板——春粉+夏绿+秋橙+冬蓝白，整体暖色调为主

### 2.4 场景元素要求

| 元素 | 位置 | 细节要求 | 对应新字 |
|:---|:---|:---|:---:|
| 大树（春） | 树冠左上 | 粉色花朵盛开，嫩绿新叶 | — |
| 大树（秋） | 树冠右上 | 金黄叶子，橙色果实 | — |
| 大树（冬） | 树冠右下 | 光秃枝干，雪花飘落，枝上有冰挂 | 冰 |
| 小男孩 | 树旁右侧 | 5-6岁Q版小孩，穿着彩色外套，仰头看树 | — |
| 小河 | 画面底部 | 蜿蜒的小河，右下角有薄冰 | 河 |
| 草地 | 树根周围 | 绿色草地，点缀野花 | 草 |

## 三、设计规范总则

| 项目 | 规范 |
|:---|:---|
| **尺寸** | 800×1000px（4:5竖版），与内页统一 |
| **标题位置** | 画面顶部 1/6 区域，居中，大字号 |
| **拼音位置** | 标题正下方，小字号，半透明或浅灰色 |
| **系列标识** | 画面左上角或右上角，小字，低调不抢主视觉 |
| **标语位置** | 标题下方、拼音上方，或画面底部 1/8 区域 |
| **新字气泡** | 暖黄色半透明气泡，分布在对应元素旁边，不遮挡关键画面 |
| **风格一致性** | Q版可爱风格，圆润线条，色彩明快，与内页插画风格统一 |
| **品牌色** | 主题色+primaryLight，与APP整体视觉体系一致 |
