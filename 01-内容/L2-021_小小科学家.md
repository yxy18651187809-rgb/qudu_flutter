## 三、故事正文（分页脚本）

### Page 1
【画面描述】小明在实验室里，穿着白大褂
【文字】小明有一个梦想，他想成为一名科学家。
【拼音】Xiǎo Míng yǒu yī gè mèngxiǎng, tā xiǎng chéngwéi yī míng kēxuéjiā.
【新字】明、有、一、个、梦、想、成、为、名、科、学、家

### Page 2
【画面描述】小明准备做实验
【文字】今天，小明要做一个有趣的实验。
【拼音】Jīntiān, xiǎo Míng yào zuò yī gè yǒuqù de shíyàn.
【新字】今、天、要、做、有、趣、实、验

### Page 3
【画面描述】小明拿出试管和显微镜
【文字】小明拿出试管和显微镜，准备开始实验。
【拼音】Xiǎo Míng ná chū shìguǎn hé xiǎnwēijìng, zhǔnbèi kāishǐ shíyàn.
【新字】拿、出、试、管、和、显、微、镜、准、备、开、始

### Page 4
【画面描述】小明仔细观察
【文字】小明仔细观察试管里的变化。
【拼音】Xiǎo Míng zǐxì guānchá shìguǎn lǐ de biànhuà.
【新字】仔、细、观、察、里、的、变、化

### Page 5
【画面描述】小明发现问题
【文字】"奇怪，为什么没有变化呢？"小明自言自语。
【拼音】"Qíguài, wèishénme méiyǒu biànhuà ne?" Xiǎo Míng zìyánzìyǔ.
【新字】奇、怪、为、什、么、没、有、呢、自、言、语

### Page 6
【画面描述】小明思考原因
【文字】小明开始思考：是不是哪里做错了？
【拼音】Xiǎo Míng kāishǐ sīkǎo: Shì bùshì nǎlǐ zuò cuò le?
【新字】开、始、思、考、是、不、是、哪、里、做、错、了

### Page 7
【画面描述】小明重新做实验
【文字】小明不放弃，他决定重新做一遍实验。
【拼音】Xiǎo Míng bù fàngqì, tā juédìng chóngxīn zuò yī biàn shíyàn.
【新字】不、放、弃、他、决、定、重、新、一、遍

### Page 8
【画面描述】实验成功了！
【文字】哇！试管里的液体变成了蓝色！实验成功了！
【拼音】Wa! Shìguǎn lǐ de yètǐ biànchéng le lánsè! Shíyàn chénggōng le!
【新字】哇、液、体、成、了、蓝、色、功

### Page 9
【画面描述】小明记录实验结果
【文字】小明赶紧拿出笔记本，记录实验过程和结果。
【拼音】Xiǎo Míng gǎnjǐn ná chū bǐjìběn, jìlù shíyàn guòchéng hé jiéguǒ.
【新字】赶、紧、笔、记、本、记、录、过、程、和、结、果

### Page 10
【画面描述】老师走过来看小明的实验
【文字】老师走过来，看了看小明的实验记录，满意地笑了。
【拼音】Lǎoshī zǒu guòlái, kàn le kàn xiǎo Míng de shíyàn jìlù, mǎnyì de xiàole.
【新字】老、师、走、过、来、看、满、意、地、笑、了

### Page 11
【画面描述】老师表扬小明

【拼音】Lǎoshī shuō: "Nǐ zhēn shì gè xiǎo kēxuéjiā! Nǐ de guānchá hěn zǐxì."

【拼音】Xiǎo Míng shuō: "Wǒ yǐhòu yào zuò gèng duō de shíyàn, tànsuǒ gèng duō mìmì!"
【新字】说、我、以、后、要、做、更、多、探、索、秘、密

### Page 14
【画面描述】小明在实验室里快乐的背影
【文字】小明想：当科学家真好玩！我要一直做实验！
【拼音】Xiǎo Míng xiǎng: Dāng kēxuéjiā zhēn hǎowán! Wǒ yào yīzhí zuò shíyàn!
【新字】想、当、真、好、玩、要、一、直

## 四、教育目标

1. **识字目标**：掌握20个新字，重点理解"科、实验、观察、发现"等与科学相关的字
2. **阅读目标**：理解故事内容，体会科学实验的乐趣
3. **科学目标**：培养科学探究精神，了解科学实验的基本过程
4. **情感目标**：培养不怕失败、勇于尝试的精神

B. 一开始没有变化
C. 显微镜坏了
D. 老师批评了他

### 练习3：连线题
将左边的词语与右边正确的解释连起来：
- 观察        A. 做实验得到的结果
- 实验        B. 仔细地看和研究
- 结果        C. 用科学方法测试

### 练习4：句子排序
将下列句子按故事顺序排序：
(  ) 小明重新做实验
(  ) 小明发现没有变化
(  ) 老师表扬小明
(  ) 实验成功了

## 六、插画需求单

### 角色设计
1. **小明**：6-7岁男孩，穿着白大褂（儿童版），表情专注
2. **老师**：温和的笑容，鼓励的眼神

### 场景设计
1. **实验室**：有试管架、显微镜、实验台
2. **实验过程**：展示试管颜色变化的过程
3. **记录场景**：小明在笔记本上记录

### 色彩方案
- 实验室：白色（干净、科学）
- 试管液体：蓝色（成功的变化）
- 小明衣服：白色（实验服）
- 背景：浅蓝色、浅绿色（清新）

### 特殊要求
- Page 4要突出小明"仔细观察"的神情
- Page 8要表现实验成功的惊喜
- Page 11要展现老师表扬小明的温暖场景
- Page 13要突出小明继续探索的决心
