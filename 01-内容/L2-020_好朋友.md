## 三、故事正文（分页脚本）

### Page 1
【画面描述】小明和小红在公园里玩
【文字】小明和小红是好朋友，他们常常一起玩。
【拼音】Xiǎo Míng hé Xiǎo Hóng shì hǎo péngyǒu, tāmen chángcháng yīqǐ wán.
【新字】明、和、红、是、好、朋、友、他、们、常、常、起、玩

### Page 2
【画面描述】小明带了一个新玩具
【文字】有一天，小明带了一个新玩具到公园。
【拼音】Yǒu yītiān, xiǎo Míng dàile yī gè xīn wánjù dào gōngyuán.
【新字】有、一、天、带、了、新、玩、具、到、公、园

### Page 3
【画面描述】小红想玩小明的玩具
【文字】小红说："可以借我玩一下吗？"
【拼音】Xiǎo Hóng shuō: "Kěyǐ jiè wǒ wán yīxià ma?"
【新字】说、可、以、借、我、下、吗

### Page 4
【画面描述】小明不愿意分享
【文字】小明摇摇头，说："这是我的，不借！"
【拼音】Xiǎo Míng yáoyao tóu, shuō: "Zhè shì wǒ de, bù jiè!"
【新字】摇、头、这、我、的、不

### Page 5
【画面描述】小红难过地走开了
【文字】小红很难过，转身走开了。
【拼音】Xiǎo Hóng hěn nánguò, zhuǎnshēn zǒukāile.
【新字】很、难、过、转、身、开、了

### Page 6
【画面描述】小明一个人玩，觉得没意思
【文字】小明一个人玩，觉得一点意思都没有。
【拼音】Xiǎo Míng yī gè rén wán, juéde yīdiǎn yìsi dōu méiyǒu.
【新字】一、个、人、觉、得、点、意、思、都、没、有

### Page 7
【画面描述】小明想起和小红一起玩的快乐
【文字】小明想起和小红一起玩的快乐，心里有点后悔。
【拼音】Xiǎo Míng xiǎngqǐ hé Xiǎo Hóng yīqǐ wán de kuàilè, xīnli yǒudiǎn hòuhuǐ.
【新字】想、起、和、快、乐、心、里、有、点、后、悔

### Page 8
【画面描述】小明去找小红
【文字】小明去找小红，不好意思地低下了头。
【拼音】Xiǎo Míng qù zhǎo Xiǎo Hóng, bù hǎoyìsi de dīxiàle tóu.
【新字】去、找、不、好、意、思、地、低、下、头

### Page 9
【画面描述】小明道歉
【文字】小明说："对不起，我不应该不分享。"
【拼音】Xiǎo Míng shuō: "Duìbuqǐ, wǒ bù yīnggāi bù fēnxiǎng."
【新字】对、不、起、应、该、分、享

### Page 10
【画面描述】小红原谅了小明
【文字】小红笑着说："没关系，我们一起玩吧！"
【拼音】Xiǎo Hóng xiàozhe shuō: "Méiguānxi, wǒmen yīqǐ wán ba!"
【新字】笑、着、没、关、系、我、们、一、起、玩、吧

### Page 11
【画面描述】小明和小红一起玩玩具
【文字】小明和小红一起玩玩具，他们笑得可开心了！
【拼音】Xiǎo Míng hé Xiǎo Hóng yīqǐ wán wánjù, tāmen xiào de kě kāixīn le!
【新字】和、一、起、玩、具、他、们、笑、得、可、开、心、了

### Page 12
【画面描述】小明明白了分享的快乐
【文字】小明想："分享真快乐！有好东西要和朋友一起分享。"
【拼音】Xiǎo Míng xiǎng: "Fēnxiǎng zhēn kuàilè! Yǒu hǎo dōngxi yào hé péngyǒu yīqǐ fēnxiǎng."
【新字】想、分、享、真、快、乐、有、好、东、西、要、和、朋、友、一、起

### Page 13
【画面描述】小明和小红拉钩

【拼音】Xiǎo Míng hé Xiǎo Hóng lāgōu, shuō: "Wǒmen yǒngyuǎn dōu shì hǎo péngyǒu!"
【新字】拉、钩、我、们、永、远、都、是、好、朋、友

### Page 14
【画面描述】太阳照着两个好朋友
【文字】太阳公公看着他们，也开心地笑了。
【拼音】Tàiyang gōnggong kànzhe tāmen, yě kāixīn de xiàole.
【新字】太、阳、公、公、看、着、他、们、也、开、心、地、笑、了

## 四、教育目标

1. **识字目标**：掌握20个新字，重点理解"朋友、分享、帮助、诚实"等与友谊相关的字
2. **阅读目标**：理解故事内容，体会友谊的珍贵
3. **社交目标**：学会与朋友相处，培养分享、帮助、原谅的品质
4. **情感目标**：培养珍惜友谊、诚实守信的品格

### 练习2：选择题
小明一开始为什么不愿意借玩具给小红？
A. 因为他不喜欢小红
B. 因为他想自己一个人玩
C. 因为玩具坏了
D. 因为小红有玩具

### 练习3：连线题
将左边的词语与右边正确的解释连起来：
- 分享        A. 对自己的错误表示歉意
- 道歉        B. 和别人一起使用或享受
- 原谅        C. 不再计较别人的过错

### 练习4：句子排序
将下列句子按故事顺序排序：
(  ) 小红难过地走开了
(  ) 小明不借玩具给小红
(  ) 小明去找小红道歉
(  ) 小明和小红一起玩玩具

### 练习5：写话练习
你有好朋友吗？你们之间发生过什么有趣的事情？写几句话告诉大家。

## 六、插画需求单

### 角色设计
1. **小明**：6-7岁男孩，一开始自私，后来后悔、道歉
2. **小红**：6-7岁女孩，一开始难过，后来宽容地笑

### 场景设计
1. **公园场景**：绿树、草地、长椅
2. **玩具**：小明的新玩具（可以是一个球或一个娃娃）
3. **拉钩场景**：小明和小红拉钩，表示和好

### 色彩方案
- 小明衣服：蓝色、白色
- 小红衣服：红色、粉色
- 公园：绿色（草地、树木）、蓝色（天空）
- 整体色调：温暖、明亮

### 特殊要求
- Page 4要突出小明"不愿意分享"的表情
- Page 5要表现小红"难过地走开"的失落
- Page 9要展现小明道歉的诚意
- Page 13要突出小明和小红拉钩的友谊誓言
