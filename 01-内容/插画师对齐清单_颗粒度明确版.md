# 字趣阅读 · 插画师对齐清单（颗粒度明确版）

> 版本：v1.0 | 创建日期：2026-05-02 | 目的：明确教研员与插画师协作的详细标准
> 适用：L1-L5 100篇故事教案插画生产

---

## 一、需求单颗粒度标准

### 1.1 必须包含的内容（缺一不可）

| 模块 | 必须提供的内容 | 详细程度要求 | 示例 |
|:---|:---|:---|:---|
| **故事信息** | 编号、标题、级别、主题、字数 | 完整 | L2-035《雨天和晴天》/L2/自然主题/280字 |
| **新字表** | 全部新字（通常在18字）+ 拼音 + 语义 | 逐字列出 | 雨(yǔ)-降水现象、帮(bāng)-帮助他人 |
| **角色设定** | 主角/配角/趣趣的出现页码 + 动作 + 表情 | 分页说明 | P03: 小兔子双手遮雨跑、惊慌表情 |
| **场景描述** | 每页背景、道具、色彩基调 | 文字+参考图 | P05: 室内、暖黄色、沙发、窗户 |
| **新字位置** | 新字在页面中的坐标范围或区域描述 | 明确区域 | P02: 右上角、文字气泡旁 |
| **分页脚本** | 每页正文 + 对应的画面建议 | 完整脚本 | P01: "今天下雨了" → 窗外雨滴、小兔子看窗 |

### 1.2 需求单可选增强内容（建议提供）

- **ASCII构图草图**：用字符画简单示意构图（非必须，但可减少返工）
- **色彩参考图**：从网络找1-2张风格参考图（Pinterest/花瓣网链接）
- **禁忌清单**：明确不想要的元素（如"不要用黑色背景"）

### 1.3 需求单审核标准（插画师收到后24小时内确认）

- [ ] 所有新字都在需求单中明确标注了位置
- [ ] 角色设定完整（主角+配角+趣趣）
- [ ] 场景描述足够具体（不会造成理解偏差）
- [ ] 分页脚本与故事正文一致（无遗漏页）

## 二、交付物颗粒度标准

### 2.1 角色设定阶段

**交付文件**：
```
{故事编号}_character_{角色名}_v1.png
```

**必须包含**：
- ✅ 正面全身图（完整身高比例）
- ✅ 侧面图（左侧面+右侧面）
- ✅ 5种基础表情（开心/难过/惊讶/生气/疑惑）
- ✅ 色值标注（附RGB色值表）

**规格要求**：
- 分辨率：不低于 800×800px
- 格式：PNG（透明背景）
- 线条：矢量风格，2px黑色描边
- 色彩：莫兰迪色系（降低饱和度）

**审核周期**：教研员24小时内反馈，插画师24小时内修改

### 2.2 分镜线稿阶段

**交付文件**：
```
{故事编号}_page{页码:02d}_sketch_v1.png
```

**必须包含**：
- ✅ 完整构图（所有角色+背景+新字位置标注）
- ✅ 新字用红色方框标注（方便教研审核）
- ✅ 文字气泡位置预留（用虚线框标注）
- ✅ 页码标注（图片角落用小型字体标注"P01"）

**规格要求**：
- 分辨率：1440×1800px（16:10比例）
- 格式：PNG（白底黑线）
- 线条：0.5-1px铅笔风格线条
- 新字标注：红色矩形框 + 字旁标注"新字：X"

**审核标准（教研员逐页检查）**：
- [ ] 每页新字与需求单一致（无遗漏、无多余）
- [ ] 角色形象与角色设定一致（无走形）
- [ ] 场景与故事脚本一致（无逻辑错误）
- [ ] 画面连贯性（角色位置/大小跨页变化合理）

**审核周期**：教研员48小时内完成审核，插画师24小时内修改

### 2.3 上色成稿阶段

**交付文件**：
```
{故事编号}_page{页码:02d}_color_v1.png
```

**必须包含**：
- ✅ 完整上色（角色+背景+道具）
- ✅ 新字高亮（黄色底色 #FFFF00 + 黑色字体）
- ✅ 阴影/高光效果（增强立体感）
- ✅ 趣趣IP形象（按规范绘制）

**规格要求**：
- 分辨率：1440×1800px（主图） / 800×1000px（封面）
- 格式：PNG（白底）
- 色彩模式：RGB
- 文件大小：单张不超过 2MB

**色彩规范**：
- 主角色：莫兰迪色系（示例：兔子#F5D6C3、小鸟#A8D8EA）
- 背景：低饱和度（示例：室内#FFF8E7、户外#E8F5E9）
- 新字高亮：黄色底色 #FFFF00 + 黑色字体 #000000
- 禁忌：不使用纯黑(#000000)以外的深色背景

**审核标准（教研员+前端负责人双重审核）**：
- [ ] 色彩与角色设定一致
- [ ] 新字高亮清晰可辨
- [ ] 无错字/漏字
- [ ] 文件命名规范
- [ ] 文件大小符合前端性能要求

**审核周期**：教研员24小时 + 前端负责人24小时 = 共48小时

## 三、审核反馈颗粒度标准

### 3.1 反馈格式规范（教研员→插画师）

**必须使用以下格式**（避免模糊表述）：

```markdown
## 审核反馈 - {故事编号} - {阶段} - v{版本号}

### ✅ 通过页面
- P01 / P02 / P03 ...

### ⚠️ 需修改页面

#### P05 - 新字位置问题
- **问题**：新字"雨"被雨滴遮挡
- **修改要求**：将"雨"字移动到右上角，避开雨滴区域
- **优先级**：P0（必须修改）

#### P08 - 角色走形
- **问题**：小兔子耳朵长度与角色设定不符（设定10cm，实际15cm）
- **修改要求**：缩短耳朵长度至设定值
- **参考图**：{故事编号}_character_小兔子_v1.png
- **优先级**：P1（建议修改）

### 📝 优化建议（非强制）
- P10：建议增加暖色调，增强"家"的温馨感
```

### 3.2 禁止的模糊反馈（避免使用）

❌ "这一页不太对"
❌ "角色画得不好看"
❌ "颜色再鲜艳一点"
❌ "新字看不清"

✅ **正确示例**：
- "P05新字'雨'被雨滴遮挡，需移动到右上角"
- "小兔子耳朵长度超出设定5cm，需缩短"
- "色彩饱和度提升至60%（当前约40%）"
- "新字字号从24pt增大至32pt"

### 3.3 插画师修改确认（插画师→教研员）

**修改完成后，插画师必须回复**：

```markdown
## 修改完成确认 - {故事编号} - {阶段} - v{新版本号}

### 已修改项（逐条对应反馈）
- ✅ P05：新字"雨"已移至右上角（附截图对比）
- ✅ P08：小兔子耳朵已缩短至设定长度（附测量图）

### 未修改项（如有）
- ⚠️ P10：暖色调调整暂未修改（原因：当前色调已符合场景需求，申请保留）

### 新增问题（如有）
- ❓ P12：发现新字"天"在脚本中未标注，是否需高亮？
```

## 四、沟通频次颗粒度标准

### 4.1 同步机制

| 同步类型 | 频次 | 方式 | 参与人 | 内容 |
|:---|:---|:---|:---|:---|
| **日报** | 每日17:00 | 工作日志更新 | 插画师 | 当日完成页数的状态码（✅完成/🔄进行中/⏸暂停） |
| **周会** | 每周一10:00 | 语音/视频 | 教研员+插画师+team-lead | 本周完成情况+下周计划+阻塞问题 |
| **里程碑报告** | 每5本绘本 | 书面报告 | 插画师→全员 | 5本完成情况+质量自检+问题汇总 |
| **紧急问题** | 随时 | 即时消息 | 插画师→team-lead | 阻塞问题、需求不明确、技术困难 |

### 4.2 响应时效标准

| 角色 | 响应时效 | 说明 |
|:---|:---|:---|
| 教研员 | 24小时内 | 审核反馈、需求澄清 |
| 插画师 | 48小时内 | 修改完成、问题回复 |
| team-lead | 12小时内 | 紧急问题协调、资源调配 |
| 前端负责人 | 24小时内 | 上色成稿审核、技术可行性确认 |

### 4.3 沟通工具规范

- **正式需求/反馈**：使用 Markdown 文档（存`04-设计/`目录）
- **即时沟通**：使用 WorkBuddy 团队消息（SendMessage工具）
- **文件传输**：通过 `.workbuddy/teams/` 共享目录
- **紧急问题**：@team-lead 提及 + 标题标注【紧急】

## 五、质量自检清单（插画师交付前必须完成）

### 5.1 分镜线稿自检（插画师自查）

- [ ] 每页新字数量与需求单一致（无遗漏、无多余）
- [ ] 新字位置标注清晰（红色方框+字旁标注）
- [ ] 角色形象与角色设定一致（无走形）
- [ ] 分页脚本与画面一致（无逻辑错误）
- [ ] 文件命名规范（`{故事编号}_page{页码:02d}_sketch_v1.png`）

### 5.2 上色成稿自检（插画师自查）

- [ ] 色彩与角色设定一致（色值核对）
- [ ] 新字高亮清晰（黄色底色#FFFF00+黑色字体）
- [ ] 分辨率正确（1440×1800px / 800×1000px）
- [ ] 文件大小≤2MB（用TinyPNG压缩）
- [ ] 无错字/漏字（逐字核对新字表）
- [ ] 趣趣IP形象按规范绘制（参考趣趣IP形象规范文档）

### 5.3 交付包完整性检查（插画师交付前）

**必须包含的文件**（以L2-035为例）：
