## 一、L3级别定位

| 项目 | 标准 |
|:---|:---|
| **级别名称** | L3 发展级 |
| **目标年龄** | 7-8岁 |
| **识字量** | 1000字（累计） |
| **故事篇数** | 20篇（第41-60篇） |
| **每篇字数** | 500-800字 |
| **每篇新字** | 25-35字（核心字+适量超纲字） |
| **故事页数** | 16-20页 |
| **主题分布** | 六大主题均衡（传统/科学/社交/成长/自然/认知） |

## 二、L3创作标准

### 2.1 故事结构（6部分）

1. **故事信息表** - 编号、名称、主题、字数、页数、新字列表
2. **新字表** - 汉字、拼音、笔画、部首、组词、是否核心字、备注（复习字标注）
3. **故事正文（分页脚本）** - 每页：画面描述、文字、拼音、新字标注
4. **教育目标** - 识字、认知、情感、能力4维度
5. **配套练习（5题）** - 图文配对、判断正误、选择题、排序题、开放题
6. **插画需求单** - 角色、场景、配色、新字图片需求、封面需求

### 2.2 分页脚本规范

| 项目 | L3标准 |
|:---|:---|
| **每页文字** | 30-50字（比L2的20-35字多） |
| **拼音标注** | 全文拼音（与L2一致） |
| **新字标注** | 每页2-3个新字（复习字也标注） |
| **画面描述** | 80-120字（比L2详细，适应16-20页） |
| **句式复杂度** | 复合句≥40%，关联词使用（因为...所以...） |

### 2.3 新字选择标准

1. **核心字优先** - 从L3核心字表（1000字范围内）选择
2. **超纲字控制** - 每篇≤5个超纲字（需图片辅助）
3. **新字重复率** - ≤10%（超出需标注"复习字"）
4. **新字分布** - 前10页引入20-25字，后6-10页巩固+少量新字

### 2.4 教育目标深度（相比L2提升）

| 维度 | L2标准 | L3标准 |
|:---|:---|:---|
| **识字** | 会认18字 | 会认25-35字，会写其中10字 |
| **认知** | 基础概念认知 | 因果关系的理解（因为...所以...） |
| **情感** | 基础情感识别 | 复杂情感理解（愧疚、自豪、同情） |
| **能力** | 简单表达 | 逻辑表达（先...然后...最后...） |

---

## 三、L3创作流程

### 3.1 创作准备

1. **确认L3核心字表** - 从`L3完整字XXX_后端导入.json`导入
2. **选择故事主题** - 从总体规划选择，确保六大主题均衡
3. **编写故事大纲** - 16-20页分页大纲（含新字分布）

### 3.2 创作执行

1. **编写故事正文** - 500-800字，符合L3语言难度
2. **制作新字表** - 25-35字，标注拼音/笔画/部首/组词
3. **分页脚本编写** - 每页：画面描述+文字+拼音+新字标注
4. **教育目标设定** - 4维度目标，符合L3标准
5. **配套练习设计** - 5题，难度匹配L3
6. **插画需求单** - 详细需求，方便插画师创作

### 3.3 质量验证

1. **结构完整性检查** - 6部分是否齐全
2. **字数/页数检查** - 500-800字，16-20页
3. **新字重复性检查** - ≤10%重复率
4. **拼音准确性检查** - 全文拼音标注是否正确
5. **教育目标匹配度** - 是否符合L3标准
