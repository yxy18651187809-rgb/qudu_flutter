## 一、背景与目标

### 1.1 背景
当前字趣阅读APP使用手机号+验证码登录，用户体验较差（需要等待短信、输入验证码）。
微信登录可大幅提升注册/登录转化率，是儿童APP的标配能力。

### 1.2 目标
- 用户可通过微信一键登录（iOS + Android）
- 后端可识别微信用户身份，关联已有账号
- 支持微信账号与手机号账号绑定/解绑
- 符合微信开放平台规范，通过审核

### 1.3 范围
| 范围 | 包含 | 不包含 |
|------|------|--------|
| 平台 | iOS + Android | Web/小程序 |
| 登录方式 | 微信授权登录 | 微信支付（Phase 2） |
| 账号体系 | 微信OpenID关联 | 微信好友/分享（Phase 2） |

## 二、微信登录流程设计

### 2.1 整体流程

```
┌─────────┐    ┌─────────┐    ┌─────────┐    ┌─────────┐
│  APP    │    │  微信    │    │  后端    │    │  数据库  │
└────┬────┘    └────┬────┘    └────┬────┘    └────┬────┘
     │              │              │              │
     │ 1. 点击微信登录                        │
     ├─────────────>│              │              │
     │              │ 2. 微信授权   │              │
     │<─────────────│              │              │
     │ 3. 返回code                │              │
     │              │              │              │
     │ 4. 发送code到后端           │              │
     ├─────────────────────────>│              │
     │              │              │ 5. 用code换access_token
     │              │              ├─────────────>│
     │              │              │              │
     │              │              │ 6. 用access_token换OpenID
     │              │              ├─────────────>│
     │              │              │              │
     │              │              │ 7. 查找/创建用户
     │              │              ├─────────────>│
     │              │              │              │
     │ 8. 返回JWT token            │              │
     │<─────────────────────────┤              │
     │              │              │              │
```

### 2.2 详细步骤

#### Step 1：APP拉起微信授权
- Flutter端调用 `fluwx` 插件
- 请求scope：`snsapi_userinfo`（获取昵称、头像）
- 微信返回 `code`（一次性授权码，有效期10分钟）

#### Step 2：后端用code换access_token
- 后端调用微信API：
  ```
  GET https://api.weixin.qq.com/sns/oauth2/access_token
  ?appid=APPID
  &secret=SECRET
  &code=CODE
  &grant_type=authorization_code
  ```
- 返回：
  ```json
  {
    "access_token": "ACCESS_TOKEN",
    "expires_in": 7200,
    "refresh_token": "REFRESH_TOKEN",
    "openid": "OPENID",
    "scope": "snsapi_userinfo"
  }
  ```

#### Step 3：后端用access_token获取用户信息
- 调用微信API：
  ```
  GET https://api.weixin.qq.com/sns/userinfo
  ?access_token=ACCESS_TOKEN
  &openid=OPENID
  ```
- 返回：
  ```json
  {
    "openid": "OPENID",
    "nickname": "微信昵称",
    "headimgurl": "https://...",
    "unionid": "UNIONID"  // 多应用统一ID
  }
  ```

#### Step 4：查找/创建用户
- 用 `unionid` 或 `openid` 查找用户
- 如果不存在：创建新用户（昵称、头像从微信获取）
- 如果存在：更新昵称、头像（可选）

#### Step 5：返回JWT token
- 生成JWT token（和现有登录方式一致）
- 返回给APP，完成登录

## 三、数据库设计

### 3.1 User Model 扩展

```javascript
// 现有User Model
const UserSchema = new Schema({
  phone: String,          // 手机号（可选，微信登录可无手机号）
  wechatOpenId: String,   // 微信OpenID（微信登录必填）
  wechatUnionId: String,  // 微信UnionID（多应用统一ID）
  nickname: String,       // 昵称（微信获取）
  avatarUrl: String,      // 头像URL（微信获取）
  // ... 其他字段
});
```

### 3.2 字段说明
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `wechatOpenId` | String | 否* | 微信OpenID，微信登录时必填 |
| `wechatUnionId` | String | 否 | 微信UnionID，多应用统一ID |
| `nickname` | String | 否 | 用户昵称，优先用微信昵称 |
| `avatarUrl` | String | 否 | 头像URL，优先用微信头像 |

*注：手机号登录的用户 `wechatOpenId` 为空；微信登录的用户 `phone` 可能为空（需引导绑定手机号）

### 3.3 索引
```javascript
UserSchema.index({ wechatOpenId: 1 }, { unique: true, sparse: true });
UserSchema.index({ wechatUnionId: 1 }, { unique: true, sparse: true });
```

## 四、API设计

### 4.1 微信登录接口

#### POST `/api/v1/auth/wechat-login`

**请求**：
```json
{
  "code": "081Mxk200FJZaK1w6a200FxutbMxk2w"
}
```

**响应（成功）**：
```json
{
  "success": true,
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "user": {
      "id": "507f1f77bcf86cd799439011",
      "phone": null,
      "nickname": "微信昵称",
      "avatarUrl": "https://thirdwx.qlogo.cn/mmopen/...",
      "needBindPhone": true  // 是否需要引导绑定手机号
    }
  }
}
```

**响应（失败）**：
```json
{
  "success": false,
  "code": "WECHAT_AUTH_FAILED",
  "message": "微信授权失败，请重试"
}
```

### 4.2 绑定手机号接口

#### POST `/api/v1/auth/bind-phone`

**请求**：
```json
{
  "phone": "13800138000",
  "code": "123456"
}
```

**响应**：
```json
{
  "success": true,
  "data": {
    "user": {
      "id": "507f1f77bcf86cd799439011",
      "phone": "13800138000",
      "nickname": "微信昵称"
    }
  }
}
```

### 4.3 解绑微信接口

#### DELETE `/api/v1/auth/unbind-wechat`

**请求**：
- Headers: `Authorization: Bearer <token>`

**响应**：
```json
{
  "success": true,
  "message": "微信已解绑，请使用手机号登录"
}
```

### 5.2 登录流程代码

```dart
import 'package:fluwx/fluwx.dart' as fluwx;

// 1. 初始化（APP启动时）
Future<void> initWechat() async {
  await fluwx.registerWxApi(
    appId: "wx1234567890abcdef",  // 微信开放平台申请的AppID
    universalLink: "https://yourapp.com/wechat",
  );
}

// 2. 微信登录
Future<void> wechatLogin() async {
  // 拉起微信授权
  await fluwx.sendWeChatAuth(
    scope: "snsapi_userinfo",
    state: "wechat_login",
  );
  
  // 监听微信回调
  fluwx.weChatResponseUpdateStream.listen((res) {
    if (res is fluwx.WeChatAuthResponse) {
      final code = res.code;
      // 发送code到后端
      authRepository.wechatLogin(code);
    }
  });
}
```

### 6.2 核心代码

#### `wechatService.js`
```javascript
const axios = require('axios');

const WECHAT_API = {
  ACCESS_TOKEN: 'https://api.weixin.qq.com/sns/oauth2/access_token',
  USER_INFO: 'https://api.weixin.qq.com/sns/userinfo',
};

async function getAccessToken(code) {
  const res = await axios.get(WECHAT_API.ACCESS_TOKEN, {
    params: {
      appid: process.env.WECHAT_APPID,
      secret: process.env.WECHAT_SECRET,
      code,
      grant_type: 'authorization_code',
    },
  });
  
  if (res.data.errcode) {
    throw new Error(`微信授权失败: ${res.data.errmsg}`);
  }
  
  return res.data;  // { access_token, openid, unionid }
}

async function getUserInfo(accessToken, openid) {
  const res = await axios.get(WECHAT_API.USER_INFO, {
    params: { access_token: accessToken, openid },
  });
  
  if (res.data.errcode) {
    throw new Error(`获取用户信息失败: ${res.data.errmsg}`);
  }
  
  return res.data;  // { openid, nickname, headimgurl, unionid }
}

module.exports = { getAccessToken, getUserInfo };
```

#### `wechatAuthController.js`
```javascript
const User = require('../models/User');
const { generateToken } = require('../utils/jwt');
const wechatService = require('../services/wechatService');

async function wechatLogin(req, res) {
  try {
    const { code } = req.body;
    
    // 1. 用code换access_token
    const tokenData = await wechatService.getAccessToken(code);
    
    // 2. 获取用户信息
    const userInfo = await wechatService.getUserInfo(
      tokenData.access_token,
      tokenData.openid
    );
    
    // 3. 查找或创建用户
    let user = await User.findOne({
      $or: [
        { wechatUnionId: userInfo.unionid },
        { wechatOpenId: userInfo.openid },
      ],
    });
    
    if (!user) {
      user = await User.create({
        wechatOpenId: userInfo.openid,
        wechatUnionId: userInfo.unionid,
        nickname: userInfo.nickname,
        avatarUrl: userInfo.headimgurl,
      });
    } else {
      // 更新昵称和头像
      user.nickname = userInfo.nickname;
      user.avatarUrl = userInfo.headimgurl;
      await user.save();
    }
    
    // 4. 生成JWT token
    const token = generateToken({ userId: user._id });
    
    res.json(success({
      token,
      user: {
        id: user._id,
        phone: user.phone,
        nickname: user.nickname,
        avatarUrl: user.avatarUrl,
        needBindPhone: !user.phone,  // 如果没有手机号，引导绑定
      },
    }));
  } catch (error) {
    res.status(401).json(error('WECHAT_AUTH_FAILED', '微信授权失败，请重试'));
  }
}

module.exports = { wechatLogin };
```

## 七、安全考虑

### 7.1 code一次性
- code有效期10分钟，且只能使用一次
- 后端需缓存已使用的code（Redis，10分钟过期）

### 7.2 access_token保护
- access_token是敏感信息，仅在后端使用，不传前端
- access_token有效期2小时，无需存储（用一次就丢）

### 7.3 UnionID vs OpenID
- OpenID：同一用户在不同应用有不同OpenID
- UnionID：同一用户在同一开放平台下有相同UnionID
- **建议**：用UnionID关联用户，OpenID作为备选

### 7.4 手机号绑定
- 微信登录后，引导用户绑定手机号（可选，但推荐）
- 绑定后，用户可选择微信登录或手机号登录

## 八、微信开放平台申请流程

### 8.1 申请条件
| 项目 | 要求 |
|------|------|
| 账号类型 | 企业账号（个人无法申请） |
| 认证状态 | 已认证（300元/年） |
| 应用类型 | iOS + Android APP |
| 审核材料 | 应用截图、功能说明、隐私协议 |

### 8.2 申请步骤
1. 注册微信开放平台账号（企业）
2. 创建移动应用
3. 填写应用信息（Bundle ID / 包名）
4. 上传应用截图（5张）
5. 提交审核（3-7个工作日）

### 8.3 审核要点
- APP必须有实际使用场景（不能只有登录页）
- 隐私协议必须包含微信登录条款
- 应用截图需展示微信登录流程

## 十、风险与应对

| 风险 | 影响 | 概率 | 应对措施 |
|------|------|------|----------|
| 微信审核不通过 | 无法上线微信登录 | 中 | 提前阅读审核规范，准备充分材料 |
| 微信API不稳定 | 登录失败 | 低 | 增加重试机制，友好错误提示 |
| 用户没有微信 | 无法登录 | 低 | 保留手机号登录方式 |
| UnionID获取失败 | 多应用账号不统一 | 低 | 用OpenID作为备选，引导用户绑定手机号 |
